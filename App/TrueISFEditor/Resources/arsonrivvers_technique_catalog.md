## 1. Architecture patterns (the ISF-specific machinery)

### 1.1 Tiny persistent buffers as GPU state machines — THE signature architectural move
1×1 (or 4×1) `PERSISTENT`+`FLOAT` passes used as scalar registers, not images:
- **Smoothed time accumulator**: stores `(accumTime, lastTIME, smoothedSpeed, validFlag)`. Per frame: `dt = TIME - prev.g`, speed low-passed `alpha = 1.0 - exp(-dt*8.0)`, `accum += dt*smoothedSpeed`. Result: dragging a speed slider glides instead of teleporting the animation. First-frame detect: `FRAMEINDEX == 0 || !(prev.a > 0.5)` (alpha as init sentinel).
- **Morph-phase servo**: `phase = mix(phase, target, 1.0 - exp(-dt*2.0*lerpRate))` — every hard scene/shape switch becomes a cinematic morph. (ProqxisShapes: 114-shape catalog scrubbed through one servo'd knob.)
- **Envelope registers**: attack/release asymmetric smoothing (`attack 5.0/s, release 1.0/s`); spring-damper `vel += (k*disp - c*vel)*dt; pos += vel*dt` — one spring-smoothed conductor scalar that many subsystems read (cell separation, follow-through). A 4×1 buffer stripes a vec3+velocity across pixels (pixel 0 = x, 1 = y, 2 = z, 3 = validity).
- **Multi-scalar state machine**: strobe energy/hitCount/lastTrigTime in RGB of one texel (CustomStrobe); DVD-logo physics `(pos.xy, vel.zw)` in one texel.
Channels R/G/B/A = independent smoothed control signals. This is how "parameter smoothing," envelopes, and physics live inside a shader with no CPU.

### 1.2 Iteration-as-passes
ISF has no compute loops across a buffer, so iteration is unrolled into pass topology:
- **Jacobi/solver unroll**: 11–20 passes all targeting the same persistent pressure buffer (WebGL-fluid port).
- **Ping-pong ×N**: `bufferA→B→A→B` (+display) = 4 sim iterations/frame without instability (ReactionDiffusion_Gen); 8-buffer chains `bufferA..H` where `iterationsPerFrame < N` turns a pass into a pure copy — variable iteration count from fixed passes (Digital Crystal).
- **Pass-per-recursion-depth**: BSP/quadtree recursion statically unrolled — one pass per tree depth, leaves enumerated by bit-testing an integer path (`pathBits`, extracted with divide/mod since no bitwise ops), composited by alpha priority (Pifragile v5/v6, Schotter multi-pass).

### 1.3 3D-in-2D volume emulation
- **Z-slice atlas**: a 3D CA volume tiled as `sqrt(res)×sqrt(res)` Z-slices in one 2D buffer, sampled with hand-rolled trilinear interpolation (8 atlas fetches) (Calabi-Yau CA). Simpler variant: horizontal Z-strips with encode/decode helpers (Organism Erosion).
- Enables true 3D cellular automata, 26-neighborhoods, volumetric state — inside ISF's 2D-buffer world.

### 1.4 Resolution economics
- Half/quarter-res sim buffers via `"WIDTH": "$WIDTH/2.0"` or `"floor($WIDTH/4.0)*4.0"` expressions; full-res display. Motion-estimation and fluid passes almost always run below full res.
- Mip-pyramid bloom: extract → cascade downsample (/2../64) → additive upsample, all as passes with WIDTH expressions; FLOAT everywhere; later versions use bilinear-optimized 7-tap Gaussians (offsets 1.3846/3.2308/5.0769) and separable H/V passes.
- Half-res volumetric raymarch + full-res unsharp-mask upscale + persistent temporal blend (poor man's TAA) (FractalVolume).
- **Resolution tiered to content granularity**: quarter-res buffer for wide strata, half-res for medium marks, full-res for the fine stylus line — three persistent buffers in one shader, each sized to what it draws (KOPIE).

### 1.5 Multi-buffer ecosystems (simulation as narrative)
- **Coupled sims**: Gray-Scott RD drives IFS fractal geometry drives datamosh feedback (EvolutionDiffusion / day29). RD chemistry → parameter bridge is *multiplicative* (`ang = base * mix(min,max,bio*influence)`) — the corpus's discovered "soul" mapping (additive versions read mushy).
- **Predator/prey buffer pairs**: organism density buffer digests a terrain-health buffer; health regenerates when the organism leaves; damage diffuses from eroded neighbors; the SDF is eaten (`d += smoothstep(damage)*0.8`).
- **Parents-as-environment genetics**: two donor sims (Gray-Scott + SmoothLife) feed a third persistent Lenia-style field; the crossfader is *inheritance pressure*, never an A/B blend. State channels: density / lineage (who fed this cell) / scar (`max(scar*0.995, deathDelta)`) / age. Mutation peaks at fader=0.5 — instability deliberately concentrated at the crossfade midpoint (OffspringEngine).
- **Proof/self-measurement buffers**: a second persistent buffer holds a processed view (Sobel edges, parity XOR) of the field, overlayable AND feedable back — "the system examines itself" (DATAFIELD).
- **History snapshot pass**: a dedicated first pass copies previous-frame state before the sim pass overwrites it, so trail deltas compare against the true previous frame (GOL_MetaCellular v14's histBuffer). Also: `bufferHold` latch pass — capture sim state on an event, crossfade live vs held (performable A/B of two simulation states).

### 1.6 GPU genetic algorithms (the research frontier of the corpus)
- Genomes as 4×4 texel blocks (8 affine transforms + topology/dynamics/color genes + age/generation/lineage metadata); generation-parity ping-pong between genome buffers; Box-Muller Gaussian mutation (`sqrt(-2 ln u1)·cos(TAU u2)`); single-point/uniform/fitness-weighted crossover; spatial/tournament/fitness-proportional selection; four fitness functions (variance, edge density, coverage, temporal stability) with EMA smoothing (day29_04).
- Cheaper sibling: continuous gene *fields* — genes as RGBA per pixel, evolution = selection-biased diffusion (neighbor influence weighted by previous-frame brightness), mutation amplified in RD-active zones ("stress-induced mutagenesis") (day29_05).

## 2. Technique ingredients (by domain)

### 2.1 Feedback & trails (the house grammar)
- `max(prev*decay, current)` — THE trail idiom (peak-hold, never dies in darks). Multi-channel grammar: `.r` peak intensity, `.g` temporal-edge energy `max(prev*decay*0.95, |Δ|)`, `.b` last value for next delta, `.a` stress.
- **Signed-delta trails**: store `rendered - clean` in a FLOAT buffer (holds negatives) so darkening effects trail too; split delta computation (non-persistent pass) from accumulation (persistent).
- **dFdx self-advection** (two lines of fluid): `g = vec2(dFdx(buf.x), dFdy(buf.x)); prev = IMG_NORM_PIXEL(buf, uv - g*amt)` — trails melt along their own gradients. Curl variant: `flowDir = mix(g, vec2(-g.y, g.x), curlAmount)` — one slider from shock-advection to swirl.
- **Luminance-pressure advection**: sample trail-luma N/S/E/W, gradient → 90°-rotated flow, displace history read + slight inward zoom ("light acts as pressure") — fluid trails with zero velocity storage.
- **Division feedback** (found-math instability, domesticated): `saturate(src / (history - k))` with wide clamps (±6..±300) and `sign(d)*max(abs(d), 0.01)` safe denominators — violent edge-seeking overdrive `mix()` can never produce.
- **Datamosh, the causal way**: model the codec mechanism, not the look — Lucas-Kanade optical flow (3×3 structure tensor, Cramer solve) → 60+ algorithm flow-transform library → flow-advected mosh buffer; luma-keyed refresh (`refresh = smoothstep(lo, hi, luma)` — bright areas are I-frames, dark keeps melting); GOP auto-reset `mod(FRAMEINDEX, gopLength) < 1`; recursive variance-driven quadtree macroblocks with 5 split styles and asymmetric appear-fast/fade-slow temporal response; block-COHERENT advection (whole block translates rigidly — reads as macroblocks, not liquid).
- Quantize the feedback *read coordinates* (not output): trails decay into JPEG blocks while live geometry stays crisp.
- Feedback decay deliberately allowed >1.0 (`MAX 1.01/1.05`) with a clamp ceiling — controlled overdrive at the edge of blowup; PANIC RESET event zeroes the buffer.
- Evolve/lineage-lock: `evolve=0` reproduces a legacy shader's exact math; every new feature scaled by `evo` — versioning as a performable parameter. SOUL knob: `mix(userParam, V3_ARCHIVED_CONSTANT, soul)` across every parameter — regression-to-canonical as a slider.

### 2.2 Simulation (CA / RD / physics)
- **Gray-Scott**: 9-point Laplacian (0.2 cardinal/0.05 diagonal), canonical f/k 0.055/0.062; presets ride the pattern-forming band `f = mix(0.030,0.058,x), k = mix(0.057,0.063,x)` so one knob morphs coral→worms→mitosis without leaving stability. **Stability governor**: `satGuard = clamp(1 - (|lap.x|+|lap.y|)*(1-stability)*0.06, 0, 1); chem = mix(raw, updated, satGuard)` — damp updates where the Laplacian is violent.
- **Rule systems**: B/S rules as float bitmasks (`mod(floor(mask/exp2(n)),2.0) > 0.5`), preset table (Life 8/12, HighLife, Seeds, Diamoeba 488/480, Day&Night, Coral, Maze...), fractional-neighbor interpolation of bits, and **stochastic rule morphing** — per-pixel hash picks ruleset A or B with morph as probability (rules can't interpolate; distributions can).
- **Stable-RNG doctrine**: hashes seeded by pixel coords + discrete local state (`stateSeed = floor(neighborSum) + self*10.0`), NEVER TIME — randomness only re-rolls when the configuration changes; no sparkle. Named HASH_SEED_* constants.
- **CA physics layer**: per-pixel velocity in buffer channels, Euler + drag + speed clamp; forces from gravity angle, Sobel edge tangents (sign stabilized by spatially-fixed random), Lucas-Kanade optical flow of the input (with aperture-problem tangent blend); velocity advects the CA's *read coordinate*.
- **Warp the sim's lattice**: 31-mode library of domain warps applied to CA read coords — flows (curl, vortex arrays, magnetic dipole Br/Bθ ∝ 1/r³, phyllotaxis, golden spiral) and fractal UV maps (Julia/Mandelbrot/Burning Ship/Newton z³=1 basins/Clifford/De Jong/Ikeda attractors/Sierpinski/Menger folds/Barnsley fern) — all returned as clamped pixel offsets so radically different math shares one strength knob. Even a Gray-Scott step used purely as a *warp field generator* for another sim.
- **Expression-tree (AST) rules**: hash-picked operator trees (18 inputs × 18 ops incl. float-emulated bit ops) with `ruleComplexity` gating tree depth; generation counter auto-mutates the rule every N frames; a 65k "rule space" scrubbed by one slider. Key lesson (in-code): the tree should select WHICH rule globally, not modify per-pixel (per-pixel random rules = noise; global rules = structure).
- **Real chaos maps**: Ikeda/Hénon/Tinkerbell/Lozi iterated per frame with orbits persisted per cell (cell-quantized so neighbors share an orbit — else incoherent noise); `chaosBound(v) = v/(1+|v|)` rational tanh substitute ("tanh is GLSL ES 3.00; this is ~10× cheaper").
- **Rock-paper-scissors color chemistry**: `dR = ra*(R*G - B*R)` etc. — cyclic 3-species Lotka-Volterra in RGB; stabilityFloor mixes toward gray so no species dies; flow-braked reaction (`brake = 1 - flowMag*k`) makes spirals form in calm zones ("weather front" feel).
- **Lenia-style continuous CA**: Gaussian ring kernels, growth `2*exp(-((n-μ)/σ)²)-1`; SmoothLife with published glider constants; equirect-mapped onto raymarched spheres (sim on a manifold).
- **Agents in fragment shaders**: 128×2 texel struct-of-arrays tracker tables (pos/age/confidence/velocity encoded per column) with spawn/track/kill state machines, block-matching search, closed-loop population control; 1×1/2×2 register-file walkers with forward+whisker anticipatory sensing and turn-cooldown debounce; physarum approximations steering by trail alpha.
- **Stochastic fractional stepping**: `steps = int(speed); if (hash(TIME) < fract(speed)) steps++` — continuously variable sim speed; per-pixel `step(1-caSpeed, hash(coord, FRAMEINDEX))` frame skipping for slow-mo without banding.

### 2.3 Raymarching & volumetrics
- **Glow accumulation** (the house look): no hit test — every step adds `gain * palette / (1 + d*d*falloff)`, step `t += max(minStep, |d|*0.5..0.9)`; `abs(d)` lets the camera fly through solids ("Phantom mode"); log-distance cosine palettes (`0.8 + cos(log(len(p)*s+1) + i*0.0744 - t + vec3(0,1,2))`) with per-step iridescence.
- **Deterministic energy-split glass**: instead of stochastic reflect/refract, split energy — reflection contributes `rPart * envColor` immediately, ray continues as refraction with `throughput *= tPart` — noise-free multi-bounce glass. Beer's law per channel (`exp(-σ·t)`, negative beer color = tinted gain); exact volumetric emission integral `emit*(1-att)/ext`; analytic environment-as-lightsource (`envArchitect`) with its own chromatic aberration; sky-as-background vs sky-as-lighting split (`bgVisibility`) so objects stay lit on black for VJ compositing.
- **Multi-hit X-ray marching**: record up to 4 surface crossings by pushing through each hit (`t += 0.05`, minimum separation), shade each layer additively — transparency without sorting. Curvature-based "laser edges": sample normals at ±eps in two axes, `pow(length(n1-n2)+length(n3-n4), 4.0)` — geometry edges become self-luminous lines. Depth-aware line weight (widen sampling eps with distance = LOD for line art).
- **Stability engineering for warped SDFs**: `distortionDanger` sums active warp weights → divides step size and inflates bounding radius; adaptive step damping `stepScale = 1 - clamp(Σwarps*0.15, 0, 0.6)`; bounding-sphere broad-phase (`~3 ops vs ~30`) with soft fade (`1-smoothstep(-0.5,2.0,bd)` — hard bounds pop); energy-based early exit (`accumEnergy > 2.5 ≈ 0.97 post-ACES`); every-other-step palette caching; first-hit lighting latch (compute shadows/AO once, reuse 2 steps).
- **Distortion racks**: 12–19 independently `if (x > 0.0)`-gated domain warps (fbm turbulence, feedback turbulence `p += amp*cos(p.zxy*freq - t)`, vortex, quadratic twist `angle = a·y + accel·y²`, cos-matrix shear `mat2(cos(a), cos(a+11.), cos(a+33.), cos(a+7.))` — deliberately non-orthogonal, gravity wells, event-horizon compression, spectral warp = additive synthesis on geometry, in-loop gravitational ray bending); phase-aware chaos gate — distortion strongest near *stable* morph phases, relaxing mid-morph (a dramaturgical rule in code).
- **SDF morphing**: raw distance-field `mix()` between unrelated shapes (metrically wrong, visually seamless under glow mapping); asymmetric smin `mix(smin(d1,d2,k), smin(d2,d1,k), blend)` with k peaking mid-morph; gaussian span-blend over up to 13 catalog neighbors (σ = span*0.35) re-mixed 20% with the crisp 2-way blend; banked coarse/fine navigation for 114-shape catalogs on two MIDI knobs.
- **Shape-library ingredients**: fibonacci-sphere spike distributions (`z = 1-2(i+.5)/N; φ = 2π·i·0.618`), parametric-curve-as-SDF (coarse 32-step + fine 16-step closest-point search + Frenet frame with degenerate-curvature fallback), gyroids at two nested scales (cavity + emissive micro-ribs), sphere inversion `p*R²/dot(p,p)` as a live topology morph, shape remix combinators (inversionDomain/inversionGate/detailBand `d -= 0.02*band*n` gated by surface proximity "to avoid SDF collapse") that mass-produce catalog variants mechanically.
- **Physical lighting when it pays**: GGX/Schlick/Smith PBR, thickness-approx SSS (march into the surface along −L, `exp(-thick*depth)`), Henyey-Greenstein phase (g≈0.7), Beer spectral absorption, thin-film interference with nanometer thickness sliders (`2·n2·d·cosθ` vs RGB wavelengths 650/510/475), OKLab-space color mixing, ACES (fitted or full matrices).
- **Voxel/DDA**: true 3D-DDA traversal (tMax/tDelta/axis masks, re-init after reflections); hierarchical LOD descent with manual recursion stacks (`walkTillExit[]` arrays); face-axis normals for free; front-to-back alpha compositing inside the DDA with early exit; world-space triplanar dithering (pattern sticks to voxel faces, not screen).

### 2.4 CV / optical flow / analysis
- Lucas-Kanade from scratch (3×3 window structure tensor, det-guarded 2×2 solve, `pow(mag,0.7)` compression); block matching (17×17→11×11, score = lumaDiff + distPenalty − featureBonus); aperture-problem fix (tangent-biased flow blended by gradient confidence); velocity-predictive search recentering.
- Signed-flow-in-RGBA encoding: `(x+, x−, y+, y−)` unsigned channels; half-res persistent analysis buffers; 3×3 Gaussian temporal smear of the flow mask.
- Jump Flood Algorithm by hand: seed pass + 8 passes at `stride = exp2(8 - PASSINDEX)`, vec4(-100) no-seed sentinel, `sampleLastPass()` PASSINDEX dispatcher; grid-sparse seeding for de-clumping; JFA → Voronoi edges/distance-glow/HUD.
- Structure tensor eigen-analysis of video building an anisotropic metric that space is *inverted through* before fractal marching (edge-direction-stretched space).

### 2.5 Generative layout & print (the "beyond ShaderToy" identity)
- **BSP/quadtree with personality**: probabilistic per-depth split probabilities; golden-ratio-weighted split tables (25% φ-major, 20% φ-minor, 20% half, thirds, √2); aspect-aware split direction; binary path-encoded cell IDs (`id = id*2 + bit`); exclusion zones carved BEFORE subdivision; stable seed streams `nextRand(inout seed){ seed = fract(seed*1.618... + 0.3141...); }`; Fisher-Yates palette shuffles in GLSL; run-length-correlated rigid/organic cut decisions.
- **Design theory as parameters**: Kandinsky shape→color correspondence and Itten contrast-of-extension as *blendable* systems (kandinskyStrength); Bauhaus tier-quantized sizes; hero-opposite-void placement with reflected-vector counterweights; triple hybrid snap (Cartesian golden lines / polar rings+spokes / diagonal band — nearest lattice wins with distance falloff); Ising-model ferromagnetic coupling as spatially-correlated chaos (patchy, not salt-and-pepper); 17 wallpaper groups + 5/7/8/12-fold quasicrystal folds as a coordinate library; mass fields + curl flow steering hatch density AND angle; tone-posterized 1/2/3-layer cross-hatching.
- **Print physics**: multiplicative ink model (`base * mix(vec3(1), inkRGB, mask)`, rich-black from plate overlap); per-channel resample misregistration (true CMYK plate offsets — impossible single-pass, needs a composite buffer); angled CMYK halftone screens (15°/75°/0°/45°); SDF-level ink bleed (`sdf - bleed*aa*k` by darkness); ink limit; paper fbm fiber; corner overshoot + pen-lift gaps + pressure variation (plotter physics); page furniture (frames, registration marks, title blocks).
- **Probability-space compositing**: dissolve imagery by dither-thresholding *existence* (`forcePaper = getDither(uv, 1-gradient, mode); ink *= 1-forcePaper`) instead of fading intensity — patterns lose whole dots, not brightness.
- **Single-pass painter's occlusion**: `ink *= 1.0 - fillMask; ink = max(ink, line)` — later shapes erase-then-stroke over earlier ones; canvas fill-order emulated in one pass.

### 2.6 Typography & data aesthetics
- Bit-packed bitmap fonts as floats/ints (3×5, 4×5, 5×5), decoded `mod(floor(bits/exp2(idx)), 2.0)` (no bitwise ops); density-ordered char ramps; bitsLow/bitsHigh split for >16-bit glyphs (float precision!); 7-segment SDF digits with per-digit segment tables; hex readouts; pseudo-kana stroke synthesis (hash-driven 3×3 stroke grids); procedural fake-OCR (hashed 5×5 dot grids with edge-biased density); full CSG vector letterforms (B-U-I-L-D from rect unions minus holes) with erosion for print key plates.
- Quine machinery: shader source as int ROMs, byte-packed 4 chars/int with float big-endian decode.
- Data-brutalism doctrine (DATAFIELD/Ikeda): binary states only (`step()` everywhere), clocked time, scanning as physical metaphor, color reserved for diagnostics/failure events, measurement HUDs (parity dots, binary beat counters, calibration brackets) — a written manifesto enforced in code.
- Hardware-failure taxonomy as 8 parameterized error modes: bit-plane corruption (arithmetic bit surgery on quantized values), row/column address faults, burst packet loss, sync-loss diagonal tear with ringing, quantization collapse (radial ADC failure), sample-and-hold droop, DCT macroblock damage, keyframe-healing bitstream desync — scan-contained ("bad sectors travel with the read head").

### 2.7 Color systems
- IQ cosine palette with palA–palD exposed as 4 `color` inputs — the standard generator color engine; golden-angle hue stepping `fract(h + k·0.618·step)`; log-distance palette phases; 120°-lobed pearlescent tints.
- OKLab (proper sRGB↔linear↔OKLab matrices + smoothstepped `oklabMix`) for perceptual blends; LCH via runtime inverse matrices as a signature "look module"; hue rotation as Rodrigues rotation about vec3(0.57735) (structure-preserving, safe on signed deltas — YIQ pair for delta-only rotation).
- **Gamut-edge blowout**: project color along a matrix-warped direction and step exactly to the RGB-cube boundary (`maxes = (step(0,dir)-c)/dir; amt = min3(maxes)`) — hard two-tone posterization onto the gamut surface.
- Blend-mode *crossfading*: `blendSlide` 0–4 float evaluates adjacent modes and mixes — continuous morph between Overlay→Add→Multiply→Screen→SoftLight (W3C-correct piecewise SoftLight).
- Full grading racks in-shader: lift/gamma/gain (per-channel), temp/tint, filmic S-curves, halation post-tonemap, luminance-weighted grain, triangular-PDF dither LAST. Correct pipeline order documented as stages: LIGHTING → SCENE(HDR) → LENS → COLOR (LGG → exposure → ACES → display-referred temp/tint) → FILM STOCK (halation → grain → dither).
- Spectral rendering: 9-sample Gaussian-lobe spectral integration for CA (lobes at t=0.78/0.50/0.22), CIE wavelength ramp 380–700nm for physically-ordered prism bands, per-wavelength temporal jitter (chromatic shimmer).
- Tone defense for accumulators: Reinhard family (`c/(c+1)`, white-preserving with whiteLevel, luminance-domain `lum/(1+lum*0.8)`), `max`-composite instead of additive glow (the definitive blowout fix), softClip `mix(clamp, tanh, k)`, ratio limiters `k = 1/(1+max(0,peak-thr)*(2+6*soft))`, aggressive final clamps.

### 2.8 Musical timing
- BPM first-class: `beatsPerSec = bpm/60`; subdivisions (1, ½, ¼, ⅛, ⅓ triplet, dotted); swing (alternate periods ×(1±swing*0.6)); beat-boundary edge detection the frame-rate-proof way: `step(0.5, floor(TIME/secs) - floor((TIME-TIMEDELTA)/secs))`.
- Envelopes: `beatEnv = attack·exp(-phase·decay)`; energy chirp (strobe frequency falls as hit energy decays); elapsed-time triggering beats phase-boundary math at low frame rates.
- Clock character: quantized time `floor(t/tick)*tick` blended by quantize amount; deterministic clock slip (`step(1-slipRate, hash(beat))` → hold → smoothstep relock); stepNoise sample-and-hold stutter; polyrhythmic strobes at ×1/×0.666/×1.5/×0.25; golden-ratio dual strobe (rates f and 1.618f never phase-lock); "quantize the time variable other effects consume" (frame hold as time surgery).
- Beat-quantized parameter mutation: hash the cycle *index* to jump parameters discretely each bar — attractor-hopping on musical boundaries.
- **Score-driven visuals**: `event` inputs (trigB/trigH/trigM) + a chord-index `long` fed from a live-coding score via OSC/MIDI, with an `internalClock` bool fallback deriving state from the piece's hard-coded cycle length — external trigs always override internal clocks ("a real note always lands") (KOPIE).
- **Coprime math against repetition**: erosion envelopes as summed half-cosine tides at coprime periods (4.3/5.9, 5.3/7.1 — never realign); shape sequencing via coprime multiplicative permutation `(a*i + b) mod 10, a ∈ {1,3,7,9}` — a guaranteed full shuffle from one seed; golden-ratio dual rates as the degenerate two-element case.

## 3. Control-surface doctrine (how it must feel to perform)

1. **Macro/conductor knobs over raw params.** One perceptual knob fans out through curated `mix()` maps to 4–15 internals (`getEff*()` / `derived*()` layers): energy/chaos macros, `unwind`, `u_Boldness`, `CellDivision (Master Motion)`, flowSpeed→{delta, gain, exp, decay} with *musical* couplings (faster flow ⇒ shorter trails). Perceptual curves (`chaos²`, `mix(0.85,0.995,memory)`); polarity documented in labels ("order ← → entropy"). The mature arc: expose everything → discover it's unplayable → collapse to 6–12 conductors (keep an "UNHINGED" everything-exposed sibling for exploration).
2. **Neutral-collapse dry/wet.** `effectAmount` must be EXACT identity at 0 (`finalUV = mix(baseUV, fxUV, amt)` — order-of-operations bugs here got all-caps FIX commits). Better: effectAmount *assembles the algorithm* (scales loop limits, march steps, reaction rates) rather than crossfading output; best: **activation fields** — a sweeping band × per-cell jitter × base so the effect spatially materializes ("no output cross-fade" as a stated design goal).
3. **Zero-default doctrine.** Every added feature defaults to 0/off so defaults reproduce the previous version exactly ("At defaults, identical to the original"); `if (param > 0.0)` gates make defaults cheap. Zero-point safety: 0.0 means ABSOLUTELY zero effect (macro bleed at rest is a bug class).
4. **Coarse/fine pairs** (`speedCoarse+speedFine` additive, `viewScaleCoarse*Fine` multiplicative); banked navigation (coarse picks a bank, fine scrubs within) for large discrete spaces; split unidirectional pairs (`zoom_in`/`zoom_out`) for MIDI.
5. **Section headers in flat hosts** — four coexisting idioms: label-only inputs (`"TYPE":"event"` or zero-range floats with `"━━ SECTION ━━"` labels), box-drawing LABELs on a group's first real slider, `"SECTION: Name"` label prefixes, numbered prefixes forcing sort (`"0.Tempo | BPM"`, `"M.Macro |"`, `"Z.Debug |"`). Glyph taxonomies: ◆ clock ◇ field ▽ scan ✕ error ▢ feedback ⚠️ danger ★ character-critical `└` sub-param `▸` mode-dependent.
6. **Presets as trims, not lockouts**: presets set base values, user slider deltas re-applied on top; preset *morphing* (cubic crossfade through 5 named parameter bundles); scene presets as multiplier sets over manual values.
7. **Danger as a feature**: sliders labeled "(Danger)" exposing solver internals (Laplacian center weight, reaction exponent, feedback >1.0); documented "unhinged zones" per parameter in header comments; instability curve-shaped (cubed response) + hard-clamped so chaos lives only at slider tops.
8. **Instrument furniture**: `event` reset ("🔴 PANIC RESET"), freeze bool + single-step event (PDE debugger), capture/hold latch, seeds as first-class performance inputs (patternSeed, gpsSeed, 0–9999), debug-view `long` dropdowns (buffer views, flow fields, fitness maps) shipped in the control surface, hidden debug at a slider extreme (persistence > 0.98 draws layout borders — "no extra slider").
9. **Host-mapping pragmatics**: floats-as-enums with legend labels ("0=Add 1=Screen 2=Overlay") for automatability; audio as plain 0–1 floats named `audio_*` (externally routable) OR `audioFFT` image sampled at `vec2(band, 0.5)`; color-typed inputs as vec3 slider bundles; MIDI CC annotations in labels; `mouseX/mouseY` floats over point2D.
10. **Hit-effect design** (kick/momentary filters): ONE hero slider defaulting to 0, mapped from MIDI/audio; shaped attack (`smoothPunch(x) = pow(smoothstep(0.0,0.1,x),2.0)*2.0` — any hit slams to full); sculpted release (buffers don't just fade — trails get eaten by animated Voronoi fragmentation, "crumble not fade"); an `intensityCurve` exponent input for mapping-curve control; everything else baked as #define constants with tuning-history comments ("Increased from 1.4") — constants-block-as-preset, versions differ mostly in defines.
11. **Depth map as a mixing fader**: with a `depthMap` input, scale every effect by nearness (`effect * (1.0 - depth)`) — near objects glitch/glow hardest; near/far get palette entries N apart for automatic subject/background color separation.

## 4. Host-quirk & stability armor (hard-won, corpus-verified)

Everything in the skill's "five things that bite" holds corpus-wide. These are ADDITIONS observed as scars/fixes:

1. **Never pass `sampler2D` as a function argument; never call raw `texture2D()` on inputs.** The single most-fixed bug class ("FIXED: Removed sampler arg" refactor waves; ColorGrading v01→v02). Duplicate per-buffer helper functions (`sampleA/sampleB`, `blur5A/blur5B`) — accepted boilerplate. One file hand-expanded VDMX's `VVSAMPLER_2DBYNORM(...)` plumbing to debug this.
2. **ISF inputs are read-only uniforms.** Writing to an input name crashes some hosts — shadow into locals first (`u_lapCard = lapCard; if (simpleMode) u_lapCard = 0.20;`).
3. **Precompute coordinates outside IMG_* macro arguments** — inline arithmetic in macro args can break the host's parser.
4. **No bitwise ops** (GLSL ES 1.00): bit tests via `mod(floor(bits/exp2(n)), 2.0)`; emulated XOR by parity accumulation; popcount by divide-loops; keep packed glyph constants ≤16 bits per float or split bitsLow/bitsHigh (a 33685504 glyph silently truncated).
5. **No const array constructors / dynamic indexing of const matrices**: Bayer matrices as unrolled if/else chains or element-wise `float M[16]` assignment; `getWeight(i)` if-chains replacing `const float[13]` initializers.
6. **`tanh` needs a polyfill** below GLSL 1.30 (`(e^{2x}-1)/(e^{2x}+1)` with input clamp ±8..±10 against exp overflow) — or better, the rational `x*(27+x²)/(27+9x²)` / `v/(1+|v|)` substitutes (~10× cheaper). `#if __VERSION__ >= 150 #define texture2D texture` shim for GL3 hosts.
7. **Float-precision time hygiene**: never `hash(uv * TIME * k)` — multiplying unbounded TIME into hash args degrades precision over a set; use `mod(TIME, 100.0..1024.0)` and ADD time. `hitCount` wraps at 10000. `fract(TIME)`-seeded grain stutters at wraparound.
8. **ALPHA_OFFSET encoding**: data stored in a FLOAT buffer's alpha can be destroyed by premultiplication when RGB≈0 — add a constant (e.g. 10.0) on write, subtract on read. Alpha also serves as init-validity sentinel (`!(prev.a > 0.5)`).
9. **Persistence traps**: legacy top-level `"PERSISTENT_BUFFERS": [...]` does NOT persist per spec (use per-pass `"PERSISTENT": true`) — a shipped shader's feedback silently never accumulated; lowercase `"persistent"` works in VDMX only; a single-target persistent pass with no display pass means buffer = output; buffers declared PERSISTENT but never read across frames are cargo cult (harmless, misleading).
10. **NaN discipline**: `sanitize()` scrub before every persistent write (`if (!(v==v)) return 0.0`); magenta NaN sentinel in debug; `max(denominator, 1e-4..1e-6)` everywhere; `normalize(g + 1e-6)` at flat regions; tan() only curve-shaped + clamped (`clamp(tan(x), -5.0, 5.0)` — unclamped tan caused infinite diagonal streaks, documented add→revert→re-add-with-clamp arc); `pow()` needs `abs()` on possibly-negative bases (or mul-chains: `x^6` as squarings).
11. **Frame-rate independence**: `dt = clamp(TIMEDELTA*60.0, 0.5, 2.0)` normalization; decay as `pow(decay, TIMEDELTA*60.0)`; px/sec scroll `vec2(sx,sy)*TIMEDELTA/RENDERSIZE`; CFL-bounded dt for sims; TIMEDELTA beat-edge detection (see §2.8).
12. **`round()` may not exist** (`floor(x+0.5)`); `%` unreliable (`imod(a,b)=int(mod(float(a),float(b)))`); `abs(int)` absent (float-cast); loop vars declared outside loops; manual `transposeMat3`; a local named `smooth` collides with a reserved word on some drivers.
13. **dFdx/dFdy on sampled textures** is host-dependent (quad-granular) — works on Metal, ride it knowingly. `fwidth(d)`-based AA (`aa = max(fwidth(d), minPx)`) is the standard stroke idiom.
14. **NEAREST filtering + math-side snapUV** together when crispness matters (hosts may force linear filtering on buffers).
15. **Anti-banding ladder**: per-pixel hash dither `/128` on all glow accumulators; camera-distance-adaptive dither (only where banding is visible); interleaved gradient noise `fract(52.9829189*fract(dot(px, vec2(0.06711056,0.00583715))))`; triangular-PDF dither `(h1+h2-1)/255` LAST in the chain; golden-angle-rotated temporal jitter on ray starts.
16. **`sample` is a reserved word on Metal/GLSL3** — `vec4 sample = ...` compiles on GL2 hosts and dies on Metal (a VDMX-macro-expanded file had to be hand-fixed to `ghostSample`/`glowSample`; its unfixed twin still ships broken). Also ban: `smooth`, `filter`, `texture` as identifiers.
17. **Identifier-parity lint** (two shipped-broken files prove the need): ISF input names are case-sensitive — JSON `PressureScale` + code `pressureScale` = compile failure; and header-transplant accidents leave bodies referencing inputs the JSON never declares. Always validate: every identifier used ∈ declared INPUTS + auto-uniforms, exact case.

## 5. Process patterns (how the extraordinary ones got made)

- **The canonical trajectory**: port/convert → parameterize ("every magic number becomes a slider," tight safety-rail ranges around chaos points) → UNHINGED (expose everything, even hash constants) → systematize (clock/quality/conductor layers) → optimize (documented [OPT] tags, bounding phases, LOD) → correctness pass (dedicated bug-fix versions with FIX comments) → simplify/"production ready" → aesthetic pivot → productize (filter conversion, presets, curated defaults). Expansion alternates with pruning; version numbers are checkpoints of private chains (filename vs internal version drift is chronic — trust code, not DESCRIPTION).
- **Rebuild rather than patch**: when architecture can't express the next idea, ground-up rewrite (Bauhaus 08/12; Digital Crystal v08 "Ground Up"; day22 v05 restart). Also the reverse: deliberate feature *subtraction* as design ("Removed Hum Bars and Curvature for a flat, stable look").
- **Artifact preservation loop**: accidental glitches get reverse-engineered into named parameterized features (X-Ray jitter, depth-fold M-curve, cylinder overwrap, "it's not a bug it's a feature" chaos framing) — and failures get archived as negative knowledge in comments.
- **Version-as-preset**: some releases change only DEFAULTs (a captured performance state); many-decimal defaults (0.437, 0.915) are frozen live-tweak captures.
- **LLM-collaborative workflow, curated**: CREDIT lines track provenance ("Gemini" → "Gemini Hybrid / Arson Rivvers" → "+ Claude"); the author's judgment shows up as parameterization, range normalization, zero-state safety, host-proofing, soul-restoration, and porting his own engines back in. Chat fossils (in-comment self-debate, "[Your Name]" templates) mark un-curated passes.
- **Two-track maintenance**: cheap live version + heavyweight studio version of the same engine kept in parallel; `_dataloss` suffix = optimization/parameterization remix protocol that provably preserves defaults; `_xfer` = transfer/crossfade-capable line.
- **Boilerplate reality**: no #include in ISF, so the personal stdlib (hash 0.1031 family + sin-dot 43758.5453, value noise + fbm, rot2, smin/smax, IQ palettes, ACES, rgb2hsv, sdBox) is copy-pasted verbatim across hundreds of files — bug fixes DON'T propagate to siblings (the √2 tilt bug lives on in v05 while v06+ are fixed). A generator should emit the canonical stdlib fresh each time.

## 6. Complexity ladder (calibrating ambition)

- **Tier 1** — single-pass toy: one idea, ≤8 inputs (SliderTest, minimal ports).
- **Tier 2** — single-pass effect stack: composed masks/warps/grades, 8–15 inputs (ASCII quantizers, CA filters, dot glitchers).
- **Tier 3** — deep single-pass system OR simple feedback: persistent buffer with `max`-decay trails, or an analytically dense single pass (spectral CA, tunnel perspective, quine engines), 15–25 inputs.
- **Tier 4** — multi-pass with real state: sim buffer + display with genuine dynamics (RD, tracker tables, JFA chains, motion estimation), quality tiers, coarse/fine controls, 25–45 inputs.
- **Tier 5** — the instrument: multiple coupled persistent systems (sim + trail + state registers ± history/proof buffers), conductor macro layer, musical timebase, presets/scenes, debug views, panic reset, documented stability engineering, 40–120 inputs. (OffspringEngine, Datamosh Pro V, CurlflowChroma, MetaCellular v14, DATAFIELD v2.4/v3.1, Proqxis v07, day25_13.)

**What makes the best ones extraordinary** (the generator's target properties):
1. A *causal mechanism*, not a look — model the codec/the chemistry/the physics/the print process and let the aesthetic emerge (datamosh from real motion estimation; misprints from real plate math; decay from real ecology).
2. Two or more coupled systems where one's state drives the other's *parameters* (RD→IFS geometry; CA→architecture reveal; organism→terrain SDF; sim→its own substrate).
3. Domain knowledge imported from elsewhere: crystallography, statistical mechanics, number theory (Zeckendorf, parastichy), color science, animation principles, codec internals, film-lab craft.
4. Performability engineered in: state that glides (servos/springs), time that swings (BPM/slip), controls that conduct (macros), safety that lets you push (governors, limiters, panic reset).
5. Self-awareness: debug views, proof buffers, registers/HUDs rendering internal state — instrumentation as aesthetic.
