## Family 1: AR_GameOfLife_filterB (v01–v06)

**Purpose & visual identity.** A video **filter** (takes `inputImage`) that runs a probabilistic Game-of-Life cellular automaton seeded and continuously re-injected by the input video's luma. The CA grid is advected by a physics layer (per-pixel velocity, gravity, edge/motion forces) and warped through a huge library of domain-warp fields, then rendered as grayscale with gamma. Categories: `["Filter", "Simulation"]`. This is the batch's most "instrument-like" system — clearly built for live VJ use.

**Architecture.** 2 passes throughout: `{ "TARGET": "golBuffer", "PERSISTENT": true, "FLOAT": true }` + bare output pass. `PASSINDEX==0` is simulation, `PASSINDEX==1` is render. The persistent float buffer is **channel-packed**: R = previous-frame input luma (for optical flow), G/B = velocity.xy in px/frame, A = authoritative CA state 0..1. Render pass reads only alpha. Init on `FRAMEINDEX == 0 || reset` (event input).

**Techniques.**
- **Probabilistic CA with range rules**: classic B/S rules generalized to `birthMin..birthMax` / `surviveMin..surviveMax`, then stochastically gated: `surviveRoll = hash(floor(readCoord) + HASH_SEED_SURVIVE + vec2(stateSeed, stateSeed*0.37))`. Deliberately **TIME-free** hashing — the comment explains the sparkle-avoidance design: "Stable (no TIME) chance gates... state-dependent so they can change as the local configuration evolves, but they won't 'sparkle' independently of the sim." The seed is `stateSeed = floor(neighborSum) + self*10.0`, so randomness only re-rolls when local state changes. This is a signature reusable trick.
- **Poor-man's optical flow**: Lucas–Kanade-style normal flow from spatiotemporal gradients: `flow ≈ -It * grad / (|grad|² + eps)`, with `It = currLuma - prevLuma` (prev luma stored in buffer R). Masked by `smoothstep(motionThreshold, ...)` and clamped to ±1.
- **Edge-force physics**: 3×3 Sobel on input luma → normalized gradient; `towardEdge = mix(normal, -normal, step(threshold, luma))` flips direction on the bright side so both sides converge on the boundary; tangent sign disambiguated by a **spatially-stable random sign** (`hash(floor(px)+seed) < 0.5 ? -1 : 1`) so cells don't flip direction over time. Forces (gravity direction knob in turns × TAU, edge attract/repel/flow, motion attract/repel) integrated with explicit Euler + drag + `clampMaxSpeed`.
- **The warp mode library** (the family's crown jewel): a `long` dropdown selecting up to **31 domain-warp fields** applied to the CA's *read coordinate* (advection source), each returning a pixel offset clamped to ±`warpAmount`: Radial waves, Spiral, Curl noise (finite-difference curl of stacked hashes), Vortex4 (four alternating-spin weighted vortices), Diamond grid flow, Golden spiral (log-spiral tangent w/ `1.61803398875` factor), Magnetic dipole (true Br/Bθ field ∝ 1/r³), Phyllotaxis flow (golden angle 2.39996), Lissajous, 4-source Ripple interference (curl of summed wave gradients), input-Edge-Tangent, Kaleido fold (`mod(a, TAU/segs)` with mirror blend `mix(a, abs(a-seg*0.5), mirrorAmt)`), Mandelbox-ish FractalFold (`p = abs(p); p = p/max(dot(p,p),0.25) - 0.45` + per-iteration rotation), Kaleido+Fractal combo, then escape-time/attractor UV maps quantified via `fract(z*k + 0.5)`: Julia, Mandelbrot, Burning Ship, Newton (z³=1 basins via complex division), Circle inversion (3 moving circles), Sierpinski triangle fold, Clifford attractor; v03 adds De Jong attractor, Ikeda map, Kleinian-style inversions with `z.y = abs(z.y)`, TrigIter, Menger-style 2D fold, Barnsley IFS fern (per-pixel seeded random iteration), Quaternion-slice 3D fold, **Mandelbrot orbit-trap gradient descent** (finite-difference gradient of min-distance-to-moving-circle trap, walk UV downhill), **reaction-diffusion warp** (a one-step Gray–Scott update computed on the CA buffer itself, F/K blended by the scale knob, then gradient of the projected V field steers the warp — RD used as a *flow field*, not a sim), and 3-level FBM domain warp (`q`/`r` nested fbm, Quilez-style).
- **Bitmask rule engine** (v04+): B/S rules as 9-bit masks decoded with float-safe bit test `mod(floor(mask / exp2(n)), 2.0) > 0.5` (no integer bit-ops — GLSL ES compatibility), `rangeToMask()` bridging the old min/max UI, and a 15-entry named preset table (Life B3/S23=vec2(8,12), HighLife, Seeds, Diamoeba, Morley, Day&Night, Replicator, 2x2, Anneal, Coral, Maze, Move, Stains) with commented rule strings.
- **Stochastic rule morphing** (v04+): `getMorphedRules` blends preset A↔B not by interpolating (impossible for discrete rules) but by **per-pixel dithered rule selection**: `pixelRand < effectiveMorph ? rulesB : rulesA`, with `effectiveMorph = morph + mutation*0.5*sin(TIME*mutationSpeed)` and a cross-coupling where the Solarize knob also pushes morph (`invert² * (1-morph) * 0.7`).
- **Continuous/Lenia-lite CA** (v03+): `caMode` Binary/Continuous/Hybrid. Continuous mode uses a Gaussian-weighted neighborhood (`exp(-dist²/2σ²)`, σ = radius*0.6, radius 1–3 i.e. 3×3/5×5/7×7) normalized ×8, activation via `smoothstep(smoothLo, smoothHi, ...)` with growth/decay rates repurposing `birthChance`/`surviveChance`. Hybrid is a plain `mix()` of the two step functions.
- **Homeostasis controls** (v02+): a 5-tap sparse `computeActivity()` (center + 4 taps at ±10px) drives `reseedWhenDead` (random rebirth biased by input: `reseedBias = inputVal*0.5+0.5`) and `dampenWhenHot` (proportional suppression above `activityMax`). Self-balancing sim for unattended live use.
- **Solarize** (v02+): upgraded from linear invert to a fold: `mix(mix(luma, 1-luma, smoothstep(amount)), 1-abs(1-2*luma), sin(amount*PI)*0.85)` — passes through invert at 1.0 but folds midtones at 0.5.
- **Edge handling as a mode**: `edgeAxis()` implements Wrap/Clamp/Mirror per axis in pixel space; all buffer taps go through `T_px()` → `handleEdgePx()`.

**Control/UI design.** ~35–50 inputs. **Section dividers implemented as LABEL text on the first input of each group**: `"━━ MAIN ━━━━━━━━━━━━━━━━"`, `━━ INPUT ━━`, `━━ CA ENGINE ━━`, `━━ PROBABILITY ━━`, `━━ DYNAMICS ━━`, `━━ WARP ━━`, `━━ STABILITY ━━`, `━━ OUTPUT ━━`. Coarse/fine pattern: strength + scale + animation-rate triplets per feature.

**Purpose & visual identity.** A **generator**: "Turing Recursive GOL" — a Game of Life whose *cells are themselves Game of Life simulations*, with a "microscope" zoom slider diving from the macro world into the micro world. **Architecture.** 3 passes: `macroState` at **$WIDTH/32 × $HEIGHT/32** (persistent, float), `microState` at full res (persistent, float), and a render/compositor pass. Downscaled sim pass is the resolution trick of note.

**Techniques.**
- **Hierarchical coupled CA**: macro B3/S23 GOL on the 1/32-res buffer; micro GOL at full res whose life is gated by its parent macro cell (`parentAlive ? run GOL + 0.001-probability thermal-noise injection : output 0`). Because micro is masked by macro, *viewing the micro buffer zoomed out reproduces the macro pattern* — so the compositor only ever samples `microState`.
- **Clock divider via random gate**: macro updates only when `fract(TIME) < macroSpeed` — a frame-rate-independent (if crude) way to slow one layer of a multi-rate sim.
- **Exponential lens zoom**: `scale = mix(1.0, 1.0/32.0, pow(zoom, 2.0))` about center; grid overlay `step(0.95, fract(uv*32.0))` fades out with zoom to "sell the computer-inside-a-computer idea."
- Cheap `fract(sin(dot))` hash; unrolled 8-tap neighbor sum using `texture2D` directly (not IMG_ macros — another sign of external origin).

**Control/UI design.** 4 inputs only (reset, zoom, macroSpeed, microSpeed — microSpeed actually unused in code). No AR conventions.

**Version evolution.** Single version; appears to be an imported concept study feeding the GameOfLife family's interest in multi-scale CA.

**Complexity tier: 3.** Multi-pass, multi-resolution, persistent, coupled sims — but tiny control surface and rough edges.

**Rough edges.** `microSpeed` input dead; micro sim runs every frame (no clock divider) so the macro/micro rate relationship is asymmetric; `updateFrame` gate can double-step when frame timing aliases `fract(TIME)`; raw `texture2D` calls are non-portable ISF style.

## Family 3: AR_Genuary2026_day2 (v01–v19 + v1; 20 files)

**Purpose & visual identity.** Generator series for Genuary 2026 Day 2, whose prompt was clearly "the 12 Principles of Animation." Evolves from a re-staged volumetric glow shape (extracted from `AR_ProqxisShapes_v22_gp`) into a **raymarched bioluminescent metaball organism that performs cell division**, with each of the 12 animation principles bound to its own labeled slider. End state (v17–v19): a grayscale-by-default, high-contrast "organelles inside hollow membranes" look with DOF and film grain.

**Architecture (end state).** 5 passes: three/four **1×1-pixel (and one 4×1) persistent FLOAT "parameter buffers"** + main render (+ in v15 only, a `colorDepthBuffer` pass and a DOF post pass):
- `timeAccBuffer` (1×1): dt-integrated time with exponentially smoothed speed — R=accum, G=lastTIME, B=smoothedSpeed, A=validity flag (`prev.a > 0.5` doubles as "buffer initialized" sentinel).
- `velocityBuffer` (1×1): playhead velocity magnitude with **asymmetric attack/release envelope** (attack 5.0/s, release 1.0/s) plus a second envelope for glow response.
- `followBuffer` (**4×1**): a spring-damper simulation storing a vec3 + velocity by **striping components across pixels** — pixel 0 = (pos.x, vel.x), pixel 1 = y, pixel 2 = z, pixel 3 = (TIME, validity). Read back with `IMG_PIXEL(followBuffer, vec2(0.5/4.0, 0.5))` etc.
- `separationBuffer` (1×1): spring-damped 0–1 "cell separation" scalar allowed to overshoot (`clamp(sep, -0.1, 1.1)`).
This is a full **CPU-style animation rig implemented in fragment shaders** — the standout architectural idea of the batch.

**Techniques.**
- **Time shaping as animation principle**: `pingPong01` phrase → `anticipationCurve(x, amt)` (localized pullback via `smoothstep(0,0.18,x)*(1-smoothstep(0.18,0.42,x))` window subtracted from the playhead) → `mix(linear, easeInOutCubic, P06)`; `quantizeTime(t, fps)` with fps `mix(60, 8, P04)` for pose-to-pose stepping. Velocity for squash/stretch obtained by **finite-differencing the playhead** (`(motion(play(t+dt)) - motion(play(t)))/dt`).
- **Volume-preserving squash & stretch**: stretch along velocity dir `sAlong = 1+k`, perpendicular `sPerp = 1/sqrt(sAlong)` — applied as an inverse transform on the SDF query point.
- **Critically-damped-ish spring follow-through**: semi-implicit Euler (`vel += (k*disp - c*vel)*dt; pos += vel*dt`) with stiffness/damping both mapped from the P05 slider (more follow-through = softer spring), then `mix(target, lagged, P05)`.
- **Metaball cell division** (v07 pivot): 4 (later 9) spheres whose offsets are `a * vec3(cos(tt*1.1), cos(tt*1.3)*arcAmp, cos(tt*1.7))`-style incommensurate LFOs, with amplitude `a = mix(0, 2.5, separation)`; polynomial `smin` (`h = clamp(0.5+0.5*(b-a)/k, 0,1); mix(b,a,h) - k*h*(1-h)`) with **separation-dependent blend radius** `k = mix(0.8, 1.5, separation)` (softer membrane while merged). Division is therefore purely emergent: one blob at sep=0, budding organism mid-range, separate cells at 1.
- **Fractional cell count** (v14): `Adv_CellCount` is a float 1–9; the fractional part grows the next cell's radius (`sphere(p - offN, rN * fract(cellCount))`) so the population slider animates smoothly.
- **Inner depth styles** (v1/v10–v13): a 6-way SDF surgery menu — Hollow Shell (`smax(d, -innerVoid, k)` smooth subtraction), Micro Organelles (hollow membrane + nucleus + orbiting organelles *inside* the cavity, combined `min(shell, organelles)` so they render through the shell), Fractal Warp (3-octave `sin(p.yzx*2/4/8)` domain warp blended by amount), Layered Shells (concentric carved rings), Cavity Network (animated void spheres + tunnels positioned by `mix(cavA, cavB, 0.5+0.3*sin)`). v18 converts the exclusive menu into **four independent, layerable amount sliders** (HollowShell/FractalWarp/LayeredGlow/CavityNetwork) on top of an always-on organelle base — menu→mixer is a recurring AR UI evolution.

P11 "Solid Drawing" scales shadow/AO/rim/spec — an animation principle mapped to *lighting fidelity*.

## Family 4: AR_Genuary2026_day3 (v01–v20; 20 files)

**Purpose & visual identity.** Genuary Day 3 generator series on **golden-ratio mathematics**. Three distinct visual regimes: (A) v01 "Binet Manifold Glass" — a raymarched semi-transparent glass sculpture of a Fibonacci manifold; (B) v02–v06 "Neon Dots" — thousands of additive glow particles on a spinning sphere warped by the Binet field; (C) v07–v20 the maturing **"AR Fibonacci Sphere" particle instrument** — Fibonacci-sphere point distribution, φ-derived warp menu, parastichy threads, trails/advection/feedback, bloom+chromatic aberration, audio/MIDI mapping. By v15 the header is re-branded "AR Fibonacci Sphere — Golden ratio driven particle system", CREDIT "Arson Rivvers" — the Genuary sketch graduating into a standing VJ instrument.

**Architecture.** v01–v02, v06: single pass. v03: 3 passes with **half-res buffers** (`"WIDTH": "$WIDTH/2"`) for dots + bloom. v04–v05: 4 passes (particles → separable Gaussian H → V → composite). v08+: canonical 5-pass chain `hdrBuffer` (FLOAT) → `trailBuffer` (**PERSISTENT** FLOAT) → `blurH` → `blurV` → composite. HDR is kept linear until the composite pass (Reinhard `col/(col+1)` → contrast → vignette → gamma 0.4545).

**Techniques.**
- **Binet field**: the family's mathematical seed. From Binet's formula Fib(n) = (φⁿ − ψⁿ)/√5, only the bounded conjugate term is used: `binet_psi(z) = cexp(cmul(z, vec2(log(1/PHI), PI)))` — complex exponentiation of ψ = −1/φ (log-magnitude `log(1/φ)`, argument π). v01 sums it over three orthogonal plane slices (`p.xy, p.yz, p.zx`) to get a 3D scalar field.
- **Log-potential isosurface DE** (v01): `d = -(log(length(field)) + Threshold) * 0.4`, smooth-bounded to a sphere with `smax(d, length(p)-2.8, 0.5)` — treating a complex field's magnitude as a potential and carving glass from its log.
- **Transparent multi-hit raymarch** (v01): on surface hit (up to 3), compute normal/fresnel, deposit a semi-transparent surface contribution, then **push through** (`t += SURF_DIST*10.0`) and keep marching with `t += max(abs(d)*0.5, 0.01)` (abs allows marching inside). Simultaneous volumetric accumulation `density = exp(-2*abs(d))` reveals internal structure. Ghost-glass without refraction.
- **Fermat quintic 5-root coloring** (v01): `croot5(w,k)` computes the 5 complex fifth-root branches `pow(r,0.2)·cis((arg+TAU·k)/5)`; each root contributes an HSV color (hue from branch index / log-magnitude / argument per `HueMode`), weight `1/(1+|root|·Glassiness)` — multi-branch complex analysis as a palette.
- **Codegolf-style dot sphere** (v02–v06, adapted from shadertoy dtf3Ws): loop `i` over [-1,1); `p = cos(i*4e4 + t.yx + 11.0) * sqrt(1-i²)` — the huge frequency `4e4` decorrelates successive `i` into pseudo-random sphere points; perspective divide `depth = pz + 2.0`; additive **inverse-square glow** `color / (dot(diff,diff) * 3e4 / dotSize² + 1e-4)`. Four layers = same loop re-phased (`-t`, `+80.0`, `+4e2`).
- **Fibonacci sphere distribution** (v08+): `y = 1 - (2k+1)/n; r = sqrt(1-y²); θ = k·GOLDEN_ANGLE` — the canonical equal-area spiral lattice, replacing the codegolf trick. Enables index-based structure (parastichy).
- **Parastichy thread rendering** (v13/v16): glowing line segments connecting dot k to dots k+13, k+21, k+34 (consecutive Fibonacci numbers = phyllotaxis parastichy counts), each thread a capsule-distance glow `thickness / (d²·1e4 + thickness·0.1)` between the two *projected* points — making the latent spiral families of the lattice visible. Thread family selectable 8/13→34/55 in v16.
- **The φ-warp menu** (v14+), all golden-ratio-derived, all faded in by `quinticEase(dist)`:
  - *Vortex*: swirl angle quantized in golden-angle units, three waves at frequencies 1/φ/φ² with Fibonacci-weighted (1,1,2)/4 amplitudes;
  - *Harmonic ("Noise")*: 5 sine waves at Fibonacci frequencies 1,2,3,5,8, each rotated an extra golden angle, amplitudes decaying by 1/φ;
  - *Spiral*: distance to log-spiral arms with slope `b = 2·ln(φ)/π` (radius ×φ per quarter turn), 21-arm interference;
  - *Binet*: the complex field, now bounded by `smoothTanh` (exp-clamped tanh) + `endpointBoost` (edge-emphasized response curve).
  Also v12's screen-space **golden log-spiral overlay**: nearest-arm distance computed analytically via `θ_for_r = ln(r)/b`, `armPhase = mod(θ - θ_for_r, TAU)`, `radialDist = distToArm · r · b`.
- **φ-harmonic pulse** (v16+): breathing modulator from three sines at f, fφ, fφ² ("never quite align, creating organic non-repeating motion"), Fibonacci-weighted, with optional peak sharpening `sign(x)·pow(|x|, 1/(1+2·shape))`.
