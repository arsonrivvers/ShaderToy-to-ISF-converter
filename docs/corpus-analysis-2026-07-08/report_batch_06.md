### Family 1: "Volumetric Box Feedback / Chaos" (AR_Genuary2026_day4_alt_v01–v15, plus v15_dataloss_v01/v02) — 17 files

- **Purpose & visual identity**: A volumetric swarm of pulsing, glitchy boxes rendered via analytic ray-box intersection (not sphere-tracing), composited through a subtractive dual-layer "difference" trick, then fed into a persistent feedback/trail buffer with edge detection and glitch/datamosh post. Reads as a pulsing neon wireframe/x-ray tunnel of boxes with CRT-glitch trails. Generator.
- **Architecture**: Always 4 dispatch stages via `PASSINDEX` over 3 declared passes (BufferB non-persistent FLOAT, BufferA non-persistent FLOAT, BufferC **PERSISTENT** FLOAT) plus the implicit final screen pass reading BufferC. PASSINDEX 0/1 render two independently-parameterized box swarms (B = "background" cull pattern at limit ~400, A = "foreground" at limit ~900); PASSINDEX 2 does edge-detect + feedback-blend into persistent BufferC; the final pass tone-maps BufferC (later versions add RGB-split there).
- **Techniques**:
  - *Analytic box intersection instead of raymarching*: the classic IQ slab test (`boxIntersection()` returning exact tN/tF) — exact and cheap for hundreds of boxes; scene depth is `min()` over all boxes.
  - *Const loop bound + runtime break as a quality dial*: `for(float i=0.; i<900.; i++){ if (i>=limit) break; }` with `Quality_Mode` (long, Low/Med/High → 250/500/900) — the canonical GLSL/Metal-safe fake-dynamic-loop idiom, present in every version.
  - *Bufferless procedural particle system*: box size, position, culling all derived purely from loop index `i` (later `idx = i + Seed_Shift*10.0`) through nested `sin()` stacks like `sin(vec3(3,2,1) + idx*Base_Scale + 0.2*sin(idx*vec3(4,3,2)) + t)` sharpened by `pow(...,vec3(6.0))` — a deterministic swarm with zero storage.
  - *Subtractive dual-layer diff*: `C -= IMG_NORM_PIXEL(BufferB, uvn); C = max(C, 0.)`, later hardened to `C = abs(C - BufferB)` ("Difference blending is harsher than subtraction") — cheap ghost-outline generator from two swarms with slightly different culling constants.
  - *Multi-tap gradient edge detection* on the scalar depth buffer: 2–3 axis-pair `abs()` differences of `IMG_NORM_PIXEL(BufferA, uvn ± sc)` thresholded against `Edge_Threshold`, injecting flat `Edge_Brightness`.
  - *Self-referential derivative-warped feedback*: 
    ```glsl
    vec2 g = vec2(dFdx(IMG_NORM_PIXEL(BufferC, uvn).x), dFdy(...));
    vec4 prevFrame = IMG_NORM_PIXEL(BufferC, uvn - g * Distortion_Amt);
    C = mix(C*4., prevFrame, Feedback_Decay);
    ```
    — uses the feedback buffer's own screen-space gradient as its warp field, giving organic "fluid" trail smear from one line of code. `Feedback_Decay` max is deliberately 1.01 (>1 allowed) with `if (Feedback_Decay > 1.0) C = clamp(C, 0.0, 50.0);` as a whiteout guard.
  - *Per-box chaos rotation*: per-instance angles `sin(idx*13.2)*pi*Chaos_Tumble`, `cos(idx*27.5)*pi*Chaos_Tumble`, applied as inverse rotations to BOTH `localPos` and `localRd` (correct object-space intersection) — turning axis-aligned slabs into a tumbling debris field.
  - *Pre-raymarch mirror/kaleidoscope*: `applyMirror()` (None / `abs(x)` / `abs(xy)` / `vec2(max,min)` fold) applied to the ray-generation UV, so symmetry is geometric rather than a raster post-fold.
  - *"Gold noise" hash*: `fract(tan(distance(xy*1.61803398874989484820459, xy)*seed)*xy.x)` — reused for block-glitch selection and per-pixel grain.
  - *Blocky screen tearing*: `blockUV = floor(uv*(20.0 - Warp_Field*5.0) + t)`, two hashes per block, thresholded (`noiseY>0.6` → horizontal offset, `noiseX>0.9` → vertical) — VHS tearing whose block size grows with intensity.
  - *Datamosh via quantized FEEDBACK LOOKUP*: `lookUpUV = floor(uvn * (500.0/Signal_Quantize)) / grid` applied to the BufferC read (not the output) — trails decay into JPEG-macroblock artifacts while the current frame stays crisp.
  - *Sin/tan "spike" geometry with safety engineering*: `mix(waveSafe(sin), waveSpike(tan), pow(Geometry_Spike,3.0))` then `clamp(motionWave,-5,5)` — deliberately courts tan()'s asymptotes but cubes the mix so danger lives only at slider top, and hard-clamps to kill NaN streaks.
  - *1-bit threshold + "sandy" grain mode*: `binary = step(Threshold_Level, val); val = binary * mix(1.0, smoothstep(0.2,0.8,noise), Dither_Amt*1.5)` — hard cutoff where the white zone is textured by contrast-boosted noise.
  - *Bayer 4×4 "Retro Dither Fade"* (v15): explicit `float M[16]` matrix, thresholding `1.0/(brightness+0.1)` against the Bayer value, mixed against smooth gamma output by `Dither_Fade`.
  - *Pre-raymarch UV quantization* (v15): `Signal_Quantize` crushes the UV before ray generation, so the *geometry itself* renders blocky ("This makes the geometry itself blocky, not just the output"), optionally double-crushing the feedback lookup too.
  - *Chromatic aberration output*: 3 taps of BufferC at `uvn ± vec2(Warp_Field*0.02, 0)` into R/G/B, with a `split<=0.0` single-tap fast path in the final clean build.
- **Control/UI design**: 8 inputs (v01) growing to ~34 (v15 remix). Naming: `Snake_Case_With_Caps` (`Swarm_Spread_X`, `Cull_Min`, `Feedback_Decay`). Macro/conductor knobs: `Geometry_Count` (0–1 multiplier on all loop limits — a true density fader), `Global_Speed` (one time base for all motion), `Warp_Field` (drives BOTH screen tearing AND RGB split), `Quality_Mode` (coarse) vs. per-axis scale/spread sliders (fine). ### Family 2: "Volumetric Neon" (AR_Genuary2026_day4_v01–v19) — 19 files

- **Purpose & visual identity**: Two (later 15) 2D SDF shapes colliding under a domain-warping noise field, colored through a hand-rolled perceptual LCH→RGB pipeline for that saturated "neon" glow; evolves into a morphable shape+interference laboratory with retro/glitch/halftone post and finally audio-reactive destruction. Generator, single-pass throughout (no PASSES, no buffers).
- **Architecture**: Pure single-pass fragment shader in every version. All motion is TIME-driven wobble; no persistence. One experimental outlier (v05) is a genuine 3D raymarcher; the other 18 are 2D implicit fields.
- **Techniques**:
  - *Hand-rolled LCH-ish perceptual color pipeline*, byte-identical across all 19 files: hardcoded `mat3 m11`/`m2`, a cofactor-expansion `inverse_mat3()`, and 
    ```glsl
    vec3 lch(vec3 c){ c.z *= 6.28;
      return max(pow(abs(vec3(c.x, c.y*cos(c.z), c.y*sin(c.z)) * inverse_mat3(m2)), vec3(3.)) * inverse_mat3(m11), 0.); }
    ```
    — OKLab-style polar hue/chroma + cubic nonlinearity, computed with runtime matrix inversion (twice per pixel!) rather than pre-inverted constants. The author's trusted "look" module.
  - *2-octave rotating-domain noise*: `single()` is gradient-style corner-dot value noise; `noise()` accumulates octaves while rotating and translating the domain (`p *= rot(k); p = 2.*p + vec2(11.*k)`) — decorrelates octaves without the usual lattice artifacts.
  - *Numeric noise derivative as domain warp*: `deriv()` central-differences the noise, and `uv -= deriv(uv*scale + 1124. + 100.*mod(floor(TIME*30.),10.), 0.01, 1) * amt` — the warp offset is re-seeded 30×/sec through 10 discrete states (`mod(floor(TIME*30.),10.)`), producing the signature stepped "electric fizzle" rather than smooth drift.
  - *SDF interference algebra*: the original "magnetic tearing" field combination `x -= sdb*sda; x -= -sdb` (product-of-distances void between shapes), later formalized into a 6-mode `apply_interference()` library: tearing, smin-subtract `-smin(-a,b,k)`, hard boolean cut `max(a,-b-buffer)`, soft XOR `smin(max(a,-b),max(b,-a),0.1)`, plasma ripple `smin(a,b,0.2)+sin(a*b*20.*p)*0.01` (interference fringes from the distance product), bubble union.
  - *The seamless index-blend router* (twice): `get_morphed_dist()` and `get_seamless_interference()` both do `id1=floor(slider), id2=ceil(slider), mix(f(id1), f(id2), fract(slider))` — direct linear interpolation of raw distance FIELDS between unrelated SDFs, making one float slider sweep continuously through the whole library.
  - *15-entry shape library*: 7 IQ-exact primitives (circle/triangle/box/pentagon/hexagon/octagon/ring) + 8 originals: Singularity (radius-proportional domain rotation `p *= rot(r*4.0 - T*0.5)` = spiral distortion), QuantumKnot (2D gyroid `abs(sin(x)*cos(y)+sin(y)*cos(T*0.5))` intersected with a disc), BioBulb (5× abs-fold + rotate), HyperRose (polar `sin(a*6+r*5-T)` rosette waves), Crystal (fold + hard subtractions), VoidShard, Artifact (asymmetric fold with `if(p.y>p.x) p.xy=p.yx;` diagonal swap and running scale correction), Coral (smin-accumulated spheres at decaying `pow(0.8,i)` radii), FractalCross (`p = abs(p)/dot(p,p) - 0.8` — 2D kali/inversion fractal), AlienRune (Mandelbox-style `fract` inversion with `scale *= k` distance correction), plus a 2D Mandelbulb power-8 slice with proper `dr` derivative tracking and `0.5*log(r)*r/dr` distance estimate.
  - *Pseudo-3D shading of a 2D field* (v17+): `calcNormal()` central-differences the composite `map()` into `normalize(vec3(dx,dy,2e))`, then Phong specular `pow(max(dot(n,light),0.),10.)*shine` and rim `pow(1.-n.z,3.)` added into the LCH lightness channel — "Liquid Chrome" relief from a flat SDF.
  - *Resolution crush as UV quantization before generation*: `grid_coord = floor(gl_FragCoord.xy/px_size)*px_size` — geometry pixelates, not just output.
  - *Bayer 4×4 dithering + posterization*: `col += ((bayer/16)-0.5)*amt; col = floor(col*steps)/steps` — dither-then-quantize in the correct order for retro color banding.
  - *Halftone ink-mask* (v18): luma → tone quantization → coverage `pow(1-Lp,1.1)` → smoothstep against Bayer threshold, plus `fwidth(L)`-based cheap edge "ink bleed."
  - *Audio-reactive mapping* (v19): five 0–1 float inputs (`audio_pixel_smash`, `audio_glitch_tear`, `audio_bit_crush`, `audio_liquid_scream`, `audio_noise_storm`) — deliberately plain floats (host/MIDI-drivable), each additively riding an existing param: pixel size +50, scanline UV tear via `noise(vec2(uv.y*10, T*20))`, bit depth `mix(2.0, depth, 1-crush)`, +0.1 noise-warp amplitude, dither+halftone trigger (`ht_mix = max(control_ht_decay, audio_noise_storm*0.8)`).

### Family 3: "Genuary Giant-Letter Halftone" (AR_Genuary2026_day5_v01–v12) — 12 files

- **Purpose & visual identity**: Procedural typography — a tiling of small SDF letters spelling "genuary" masked inside one GIANT letter (fixed "G" at first, later continuously morphing G→E→N→U→A→R→Y), rendered through a rotatable, jittered, Swiss-Punk Bayer halftone with edge halos, plus an ASCII-density-fill layer. Generator (also usable as a stylization "Post" per its categories), single-pass.
- **Architecture**: Single pass, no buffers. `getProceduralImage(uv)` is a pure analytic function invoked up to 6× per pixel (base, jittered halftone sample, 4 edge-detect neighbor taps) — a "re-render the scene N times per pixel" pattern only viable because the generator has no loops-over-primitives and no texture reads.
- **Techniques**:
  - *Hand-built CSG vector font, two glyph sets*: `sdLetter()` (lowercase g/e/n/u/a/r/y) and `sdGiantLetter()` (uppercase G/E/N/U/A/R/Y) built from `sdCircle`/`sdBox`/`sdSegment` + `opSmoothUnion` + boolean cuts. Ring strokes via `abs(sdCircle(...)) - w` (annulus from a distance), half-cuts via `max(d, ±p.y + c)`, and the fragile-but-scalar trick `max(d, -(p.x>0.1 && p.y<-0.1 ? 1.0 : -1.0))` for masking the "e" aperture (boolean condition → ±1 select — near the ternary hazard zone but scalar so it compiles).
  - *Continuous glyph morphing by SDF-field mix*: the same floor/ceil/fract router as Family 2 — `mix(sdGiantLetter(idx1), sdGiantLetter(idx2), blend)` with `mod(totalMorph,7.0)` looping and explicit `if (idx2 >= 7) idx2 = 0;` wraparound.
  - *Ease-with-hold morph curve* (v10+): `getEase(t){ if(t<0.3) return 0.; return pow((t-0.3)/0.7, 3.0); }` — each letter holds static 30% of its cycle then eases in cubically; motion-design polish over raw lerp.
  - *Nested-cell composition*: `pattern_uv = uv*patternScale (+ scroll*TIME)`; `cell_id = floor()`, `cell_uv = fract()-0.5`; letter chosen per cell by 5 selectable layout rules (Diagonal `x+y`, Horizontal `x`, Vertical `y`, Zipper `x + (y%2)*3` brick offset, Random `hash21(cell_id)*6.99`); tiny-letter mask multiplied by giant-letter mask (`pattern_mask * g_mask`) = text-fills-the-letterform.
  - *Rotatable halftone screen decoupled from content*: rotate UV into grid space (`gridUV = rotM*(uv-0.5)+0.5`), snap and hash there, then rotate the snapped/jittered coordinate BACK to world space (`invRotM`) before sampling the image — a genuine angled halftone plate (the dot grid spins; the image doesn't). Manual `gridRot` + automated `gridSpin*TIME*20` pair.
  - *Jittered halftone sampling*: per-cell `hash21(cellId+seed)` → angle → `jitterAmount/gridSize * vec2(cos,sin)` offset on the snapped sample point — "hand-printed" registration error.
  - *Bayer subdivision halftone*: coverage `cov = pow(1-Lp, gammaCurve)` from tone-quantized luma; per-cell subgrid `subIJ = floor(fract(uv*gridSize)*subdiv)`; ink mask `smoothstep(T_bayer-soft, T_bayer+soft, cov)` — softness turns ordered dither into soft-dot halftone.
  - *Edge + halo via scene re-evaluation*: 4 extra `getProceduralImage(snap(uv±off))` calls → gradient magnitude → `edge` darkening and `halo = smoothstep(0, 1/haloRadius, edge)*edgeHalo` lightening — halo rings around letter edges.
  - *ASCII density injection* (v09+): a 4×5 bitmap font for a 10-character density ramp (space . - ' : + = * O #) with glyph bitmasks stored as **decimal floats** (1536.0, 240.0, 36864.0…) and bits extracted by `mod(floor(bits/pow(2.0,bitIndex)),2.0)` — explicitly commented "Replaced bitwise shifts '<<' with standard math to support GLSL ES 1.0." Character choice per cell is driven by the giant-letter SDF's interior depth (`smoothstep(0,0.3,abs(d))*0.8 + hash*0.2`), so denser glyphs cluster deep inside the letterform — volumetric ASCII shading of a 2D SDF.
  - *Full grading stack*: effectAmount master fade with `if(t<=0.001) return base;` early-out, then desat → contrast (`mix(vec3(0.5), c, 1+k*2)`) → saturation → gain/lift → output gamma, every stage scaled by `t`.
- **Control/UI design**: camelCase naming (third distinct convention in the batch). ~23–30 inputs. The standout: from v08 on, **section-divider inputs** — zero-cost `"TYPE":"event"` entries whose LABEL is a header: `{"LABEL": "--- ANIMATION & CONTENT ---", "NAME": "separator_anim", "TYPE": "event"}` — grouping ANIMATION/ASCII/HALFTONE GRID/GEOMETRY/TONE & EDGES/COLOR & POST. - **Recurring patterns / style fingerprints**:
  - **The "seamless index-blend router"** (`floor/ceil/fract` + `mix` of raw SDF fields or function outputs) appears independently in Families 2 and 3 for shapes, boolean modes, and letters — the author's signature way to turn any discrete N-way switch into one continuous performable slider.
