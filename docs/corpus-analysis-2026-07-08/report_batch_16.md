## Family 1: IFS Evolved / Bio-Mosh (day29_01 – day29_08, 8 files)

**Purpose & visual identity.** Generators (08 is the filter spin-off): an IFS (iterated-function-system) fractal whose parameters are driven per-pixel by a live Gray-Scott reaction-diffusion simulation, then smeared by a gradient-driven "datamosh" feedback pass. Visual identity: crisp orbit-trap fractal linework that breathes and mutates organically, with melting motion trails.

**Architecture.** Canonical 3-pass stack, all versions: `sim_buffer` (PERSISTENT+FLOAT, Gray-Scott A/B in .rg), `render_buffer` (IFS raster), `mosh_buffer` (PERSISTENT+FLOAT temporal feedback), plus a final passthrough branch (`PASSINDEX` beyond declared passes reads mosh_buffer — the author consistently exploits the implicit final screen pass). Dispatch is a clean `if (PASSINDEX == n) pass_x()` router with named `pass_simulation / pass_render / pass_mosh` functions. Variants:
- day29_03 adds a 4th `control_buffer` (FLOAT, non-persistent) — a dedicated "translator" pass.
- day29_04 explodes to **7 passes**: ping-pong `genome_buffer_a/b` (both quarter-quantized `"WIDTH": "floor($WIDTH/4.0)*4.0"` expressions — resolution-expression use is rare and deliberate), `fitness_buffer`, `reaction_buffer`, `phenotype_buffer`, `analysis_buffer`, `composite_buffer`.
- day29_08 converts the system to a FILTER with only 2 passes (render + mosh), warping the IFS by video edges.

**Techniques.**
- *Gray-Scott RD, hand-rolled*: 9-tap Laplacian with 0.2 edge / 0.05 corner weights, `a += Dا·lap.r − a·b² + feed·(1−a)`, `b += 0.5·lap.g + a·b² − (kill+feed)·b`, clamped. Diffusion ratio hard-coded 1.0/0.5 in early versions, exposed as `diffusionA/diffusionB` plus a Laplacian **anisotropy bias** (`cw = 0.2 + bias*0.1; dw = 0.05 − bias*0.025`) in Phase 2.5/2.6.
- *FRAMEINDEX-gated seeding*: `if (FRAMEINDEX < 5 || rebirth)` reseeds — the standard host-quirk init idiom. Seed geometries evolve per version: center dot + hash scatter (v3) → geometric line+dot seeding (Translator) → a `seedMode` enum (Center+Scatter / Ring / Grid / Noise Field) with `seedRadius/seedFrequency/seedThreshold` (2.5/2.6).
- *Bio→IFS parameter bridge* (the family's core invention): the RD field is sampled at screen UV and mapped into IFS parameters per pixel. v3's "magic sauce," later canonized as **multiplicative bio-angle**: `ang = (angleSteps * TAU) * mix(bioAngleMin, bioAngleMax, bio.r * bioInfluence)` — angle *scales* with chemistry rather than adding, which the author explicitly identifies (in 2.5's comments) as what gave v3 its "soul." Additive and hybrid modes are provided as an enum for comparison.
- *IFS loop*: `p = abs(p); p = rot2(p, ang + i*drift); p = p*scl − offset; p *= 1/(1 + dot(p,p)*inversion)` — abs-fold + per-iteration angle drift + **soft sphere inversion** (the `1/(1+r²k)` term keeps orbits bounded and produces the lacy look). Box orbit trap `max(|x|,|y|)`, rendered as `exp(-trapMin * lineTightness)` then smoothstep-thresholded. `const`-bounded loop `for i < MAX_ITERS` with runtime `if (i >= itN) break` — the documented Metal-safe loop idiom, used everywhere in this corpus.
- *Orbit-trap toolbox* (2.5+): 6 trap types (Box/Circle/LineX/LineY/Cross/Star with `cos(ang*5)` petal radius), a **second trap blended via `mix(d1, min(d1,d2), trapBlend)`**, plus `trapAccumulate` mixing min-trap against average-trap `exp(-trapSum/N * tight * 0.5)`.
- *Fold/symmetry toolbox* (2.5+): fold enum {abs, triangle (0.866 kite fold), hexagonal, spherical (r²<0.25 → ×4, r²<1 → 1/r²), none}; polar kaleidoscope `applySymmetry` (angle mod TAU/folds recentred), mirrorX/Y bools.
- *Datamosh feedback* (signature move of the whole corpus): flow field from screen-space derivatives of luma, `flow = vec2(dFdx(luma), dFdy(luma)) * moshForce * mag`, history dragged `texture2D(mosh_buffer, uv − flow*offset)`, and a **luminance-keyed refresh**: `refresh = smoothstep(refreshLow, refreshHigh, luma); final = mix(dragged*decay, current, refresh)` — bright areas act as "keyframes," dark areas keep melting. v3-vs-Rec709 luma weights are exposed as a switch because equal weights (0.333) change the mosh's character.
- *Feedback geometry*: zoom/rotate of the feedback UV (`fbUV = rot2((uv-0.5)*(1+zoom)) + 0.5`) added in 2.5 — the "infinite corridor" ingredient later exported to DATAFIELD.
- *Genetic algorithm on the GPU* (day29_04, the tour de force): each 4×4 pixel block of a float buffer is a **genome** — rows 0-1 hold 8 affine transforms (angle, scale, offset.xy), row 2 holds topology/dynamics/color/render genes, row 3 metadata (age, generation, lineage). Implements: Box-Muller **Gaussian mutation** (`sqrt(-2 ln u1)·cos(TAU u2)`), drift/point/block/structural mutation tiers with separate rates, three crossover operators (single-point at pixel index, uniform via `step(0.5, hash44)` mask, fitness-weighted blend), three selection operators (spatial neighborhood with wraparound, tournament-of-K reading a fitness texture, fitness-proportional-ish biased spatial), elitism gating, generation boundaries via `floor(FRAMEINDEX / generationLength)` and **generation-parity ping-pong** between genome buffers A/B (each pass writes only on its parity turn, else self-copies). Four fitness functions computed from the previous frame's phenotype (local variance "complexity," gradient "edge density," coverage, temporal stability vs. an analysis buffer), with EMA smoothing and a frames-since-improvement counter. Phenotype pass tiles the screen into `tileSize` cells, each rendering its genome's IFS in local −1..1 coords. Four debug view modes (Phenotype/Genome Vis/Fitness Map/RD Field).
- *Continuous gene fields* (day29_05, the counter-design): instead of discrete genomes, genes are RGBA fields per pixel; evolution = Laplacian diffusion + **selection-biased diffusion** where neighbor influence is weighted by previous-frame brightness (`weight = 0.1 + pow(fitness, 1+2s)·s`) — fitness as implicit phenotype brightness; mutation rate amplified ×(1+3·rdActivity) in RD-active zones ("stress-induced mutagenesis"). Genuinely non-standard.
- *Conductor system* (2.5/2.6): macro knobs (CHAOS, FORM DISSOLVE, TEMPORAL SMEAR, COLOR INTENSITY, CINEMATIC DRAMA, SOUL) mapped through `getEff*()` functions that mix user params toward preset targets; **SOUL** is a single knob that mixes every parameter toward v3's exact archived constants (`#define V3_INVERSION 0.18`, `V3_FLOW_MAG 100.0` etc. in 2.6) — parametric nostalgia, a version-archaeology-as-feature move I've not seen elsewhere. `formDissolve > 0.8` overrides foldMode to "None," >0.6 to "Spherical" (threshold-stepped macro→enum).
- *Post stack* (2.5/2.6): ACES + Reinhard tonemap enum, exposure/gamma, vignette, film grain — 2.6 upgrades grain to 3-octave (0.6/0.3/0.1 at 1×/2×/4× RENDERSIZE).
- *Cosine palettes*: classic `a + b·cos(TAU(c·t+d))` bank (Neon/Fire/Ice/Earth/Synthwave/Mono) + color-index sources enum (iteration escape, trap distance, bio, orbit average).
- Filter variant (08): IFS coordinates warped by Sobel edges of the input video (`p += edges * edgeIntensity`), 5 blend modes (Normal/Add/Multiply/Screen/Overlay with `step(0.5, luma)` branch select), mosh flow driven by *video* edges so trails follow subject contours; `dryWet` master.

**Control/UI design.** Escalates from 14 flat floats (01) to ~70 inputs (2.5/2.6). Conventions: prefix labels grouping ("Bio:", "Mosh:", "IFS:", "Gene:", "Fit:"); **section dividers as dummy event inputs** with box-drawing labels (`{"NAME":"ui_rd","TYPE":"event","LABEL":"━━ REACTION-DIFFUSION ━━━━"}`) — 2.5 also uses ⚠️ to flag "dangerous/deep" params and ★ for character-critical ones; `rebirth` event input for reset (checked in sim AND mosh passes); `long` enums with LABELS arrays everywhere; conductor knobs listed first. 2.6 strips emoji from labels (host font-compat scar) and adds pan/rotate view transform and a functioning `seed` (v2.5's seed did almost nothing — fixed by overloading `hash12(vec2,float)` and a `seedPert` angle nudge).

**Version evolution.** 01 (v3): the accidental classic — multiplicative angle mapping. 02: rebirth event + stability retuning (offset 0.5, tighter smoothstep, contrast pow). 03 (Translator): decouples chemistry from geometry via a control-extraction pass that **quantizes** RD density into snapped angle/scale/bias/regime channels and samples the control buffer at grid-cell centers (`floor(uv/cell)*cell + cell/2`) "for the Machine look," with 3 folding regimes (Mirror/Turbine/Fracture). 04: maximal genetic architecture. 05: retreat from 04's complexity to continuous gene fields (simpler, more visual payoff). 06 (2.5): "SOUL RESTORED" — an explicit reconciliation commit: the UNHINGED feature buffet had lost v3's character, so v3's constants are archived in-code and made reachable by one knob. 07 (2.6): bug-fix release — `#if __VERSION__ >= 150 #define texture2D texture` **GL3 compatibility shim** (a real host-versioning scar, comments say "FIXES TEXTURE ERRORS"), UV clamping on all feedback/chromatic samples, working seed, glowMask fix, edgeMultiplier exposed. 08: productized filter spin-off. The trajectory documents a full research arc: discovery → feature explosion → over-engineering → retrenchment → soul-restoration → hardening → productization.

**Complexity tier: 5** (day29_04 alone is a 7-pass evolutionary computation platform; the family norm is 3–4-pass simulation+feedback with conductor macros).

**Signature moves.** Multiplicative bio-parameter mapping; "SOUL" archival knob; luminance-keyed datamosh refresh; genome-in-texture-blocks with ping-pong generations; selection-biased diffusion; conductor `getEff*()` layer; quantized control-buffer "translator" pass.

## Family 2: Neon Mountain / Silent Architect (day30_01 – day30_12, 12 files)

**Purpose & visual identity.** Filters taking `inputImage` + `depthMap`: reconstruct a glowing 3D wireframe mesh from a depth map — synthwave grid-over-terrain — evolving into "The Silent Architect," a brutalist blueprint aesthetic (cyan/pink/purple/white palette, sheared rows, quantized depth slabs).

**Architecture.** Single-pass, but **algorithmically multi-object**: for each fragment, a search loop over a neighborhood of grid cells (radius 1–8) reconstructs 3D vertex positions from depth samples, projects them, and accumulates distance-to-segment glow for up to 4 edges per cell (H, V, two diagonals) plus vertex points — a fragment-shader **splatting/rasterizer** for a wireframe mesh, no geometry stage. Later versions restructure the identical inner body as a `#define DRAW_EDGE(ni, nj) {...}` macro (with `#undef` hygiene from 05 onward) — a notable macro-as-inline-function idiom to dodge GLSL function-out-parameter clutter.

**Techniques.**
- *Depth-to-3D lift*: `p0 = vec3(pos2D.x, (d−0.5)*DepthScale, pos2D.y)` (depth becomes height Y, screen Y becomes Z), tilt via 2D rotation of `p.xy`, "perspective shift" as a shear `proj.x += p.y * TiltY * 0.5`; Silent Architect versions switch to true perspective `p.xy / (1.0 − p.z * LensCompression)`.
- *Bounded glow*: `core = smoothstep(w*1.2, w*0.15, d)` plus Gaussian skirt `exp(-(d/(6w))² * GlowFalloff)`, with **density-normalized brightness**: `densityRatio = 40/gridRes; glowDensityScale = densityRatio²` so changing grid resolution keeps perceived luminance constant — a thoughtful invariant.
- *Depth-dependent line thickness*: `1 + pow(1−d, ThicknessCurve) * (nearMax−1) * amount * (1+|projY|·0.5)`, clamped — near lines thick, far thin, curve exposed.
- *Edge enhance*: width × `(1 + |d0−d1| * EdgeEnhance * 20)` — depth discontinuities become emphasized silhouettes; separate `SilhouetteBoost` from depth-gradient magnitude.
- *Depth processing chain*: brightness-blend fake depth (`mix(raw, raw*(0.5+brightness*0.5), amt)` for footage without a real depth map), signed **DepthInversion** with the "famous M-curve" double-mix folding at |0.5| (a discovered glitch promoted to feature; 05 clamps inner blend to fix overshoot), and DepthQuantize → topographic contour slabs ("Data Decay"/"Brutalism": `levels = mix(32, Brutalism, decay)`).
- *Chaos Engine* (02→): a global routing block computed once in main() — `ChaosAmount` × time-evolution envelope (`breathe = sin(t/2)·0.5+0.5` + cubed pulse), routed by `ChaosTarget` enum to geometry/projection/color/temporal subsystems, each `eff*` global = base param + chaos × hash31(ChaosSeed) offsets, clamped with **deliberate over-range** ("Allow overshoot!" — scatter to 2.0, cylinder wrap to 1.5 where overwrap folds `proj.x += sin(proj.y*5)*overFold`). Comments name the failure-aesthetics: "Grid Singularity," "Vertex Explosion," "Projection Shattering," "it's not a bug, it's a feature."
- *ProjectionBreak*: systematic per-vertex hash offsets + wrong depth contribution (`wrongDepth = p.y * (1 − break*2)`) — intentional wrong-projection as material.
- *Temporal smear*: per-grid-vertex sinusoidal UV offset `sin(TIME*freqX + gridPos.y*SmearWave)` with exposed X/Y frequency ratio — mesh vertices crawl over the video.
- *Quality system* (03–05): a single `Quality` slider drives search radius (quadratic mapping, later stepped table with comments giving cell counts), octave counts, gradient-computation skip thresholds, diagonal skipping, early distance culling (`cellDist > cullDistance continue`), edge-color simplification (neighbor color only at Q>0.75), and even a whole-frame single-color ultra-low path (Q<0.15) — the most systematic LOD design in the corpus. 06/07 replace stepped quality with a **smooth float radius + per-cell `smoothLimit = clamp(fRadius − dist + 1, 0, 1)` fade** so the Quality knob is performable without pops.
- *Ambient color field* (03+): replaces the original one-liner mountain formula `1.0 + sin(p.x·F + p.z·F + t + vec3(2,7,0))` (deliberate >1 additive clipping = neon) with a layered noise system: quintic-interpolated 3D **gradient noise**, domain-warped fBm (per-octave xy/yz rotations "to break up alignment"), quality-adaptive cheap value-noise fallback, mapped through `elegantPalette` — an HSL dual-journey palette (cool cyan→violet vs warm purple→orange selected by `ColorWarmth`, sat/lightness gently sinusoidal in t), `NeonBias` re-introducing the overdrive (`col*(NB+0.5)+(NB−0.5)*0.5`), and `PaletteGene` blending a complementary palette by spatial noise.
- *Silent Architect* (09–12): structural entropy — **row shear** `gIdx.x += (hash21(row, seed)−0.5) * E * ShearForce` (whole mesh rows slide like fractured strata), `stepNoise` (hash held then `smoothstep(0,0.1,fract)` snap = stuttering, sample-and-hold time), fixed 4-stop architectural palette with `col.bgr` warmth swap trick, `GridLogic` fading horizontal+diagonal edges to leave scanline-like verticals, intersection VertexGlow, and (12) real compositing blend modes: Screen, Multiply, **Color Burn** `1−(1−base)/max(blend,ε)`, Overlay.

**Control/UI design.** Introduces `"TYPE":"comment"` SECTION_* dividers (vs family 1's event dividers — the author tried both host conventions); `[Q>0.7]`-style annotations telling the performer which knobs are quality-gated (05); DEEP MAGIC section exposing previously hard-coded falloffs/curves; Master → Chaos → subsystem ordering. 30–40 inputs typical.

**Version evolution.** 01: fusion of two prior shaders (depth wireframe + "Glowing Mountain" colors — lineage remix). 02 UNHINGED: chaos param exposure + projection break/cylinder wrap/scatter/quantize. 03 v2: Chaos Engine consolidation + Quality + elegant ambient color field replacing raw sin palette. 04: aggressive optimization pass (value noise, per-quality code paths, precomputed smear, edge-color LOD). 05: correctness pass (respect user DiagonalMode except ultra-low Q, clamp inversion inner blend, `#undef DRAW_EDGE`, early-out radii). 06 v3: rewrite-simplification — fewer inputs, smooth quality, chaos kept ("Production ready"). 07 v3b: re-adds temporal smear, min/max depth range windowing, quantize, GradientSmooth, PaletteGene onto the clean base. 09 v4: pivot to Structural Entropy (shear/decay/stutter targets). 10 v5 (Silent Architect): minimal 27-control statement piece, fixed radius. 11 v8: unified schematic (GridLogic, vertex glow, quality back, full output mixing). 12 v10: layer-mode compositing edition (tabs-indented file — different editor session). Trajectory: fuse → unhinge → systematize → optimize → correct → simplify → re-enrich → aesthetic pivot → productize.

**Complexity tier: 4** (single-pass but with a hand-built mesh rasterizer, LOD system, chaos routing, and a layered noise/palette engine).

## Family 3: ChaoticLines (day31_01 – day31_08, 8 files)

**Purpose & visual identity.** Generators: a tiled grid of cells, each containing N chaotic vertical lines oscillating/jumping on hashed parameters — evolving into a full "visual instrument" simulating a faulty digital machine: clocks, slips, logic gates, registers, glyph annotations, a macro conductor, cellular automaton and a microprogram sequencer. Monochrome-first; color reserved for diagnostics/events.

**Architecture.** 01–02 single-pass. P1/P2 single-pass with big helper libraries. P3+ two passes: `feedbackBuffer` (PERSISTENT+FLOAT) + screen pass, with an anonymous `{}` final pass in the PASSES array (author's convention for "screen"). The line evaluator threads an enormous explicit parameter list (25+ args) rather than globals — deliberate purity, at readability cost.

**Techniques.**
- *Hash with exposed constants*: `hash31(p, mod3, accum, magic)` — the canonical MOD3 hash where `vec3(0.1031, 0.11369, 0.13787)`, 19.19, 43758.5453, 12.9898 are all **user sliders** flagged ⚠️. Turning "magic numbers" into performance controls ("HASH CHAOS", "SEED ALCHEMY", "TILE SEED" sections) is this family's founding idea: the PRNG itself becomes an instrument.
- *Line engine*: per line i, `n = hash31(i + seed*seedMult + cycle*cycleMult)`; base X in [xMin,xMax], probabilistic jump displacement (`step(jumpThresh, fract(sin((t+n.z)*scramble)*magic))`), sinusoidal motion with hashed speed/phase/amplitude, hashed thickness modulated by a **BPM duty-cycle pulse** (`pulse = step(fract(t/beatPeriod + tilePhase), Duty)` → thickness lerp — "fakeAudio"). Cycle-quantized reseeding: `cycle = floor(tileTime/cycleLength)` re-rolls all lines every cycle, with a per-tile hashed time offset so tiles desynchronize.
- *Line SDF + morphology* (P2): rotated-line SDF `|rp.x − pos| − w/2`; render modes fill/outline/hollow/edge derived from the SDF; **morph erode/dilate = SDF offset** `sdf − morphAmt*0.2` — mathematically clean morphology without image-space passes.
- *Clock system* (P1, the family's masterstroke): time quantized to ticks (`floor(t/tickDur)*tickDur`, blend by `timeQuantize`), per-tile phase offsets and slow sinusoidal drift, and **clock slip**: per-beat deterministic trigger `step(1−slipRate, hash(beat·7.13 + seed·17.31))`, a hold-then-smoothstep-relock envelope (`slipHold`, `clockRelockSharpness`), hashed slip amount — tiles fall off the grid and audibly "re-lock." Musical failure simulation, fully deterministic (hash-of-beat, no state needed).
- *Logic modes* (P1): per-pixel line hits collected into a `float hits[32]` array, combined by SUM-threshold / **XOR (odd parity)** / OR / AND with a `bitDepth` window — the frame becomes a logic-gate evaluation.
- *Threshold system*: quantized threshold steps, beat-phase threshold modulation, **hysteresis** simulated by biasing threshold with an early-beat hash sample enveloped by `sin(localT·π)`.
- *Scan/raster* (P2): moving read-head mask in 4 axes with wraparound distance, **rolling shutter** (scan position offset by coordinate → time skew), and deterministic per-beat read errors in 3 flavors (stutter/skip/jitter of the scan position).
- *Diagnostics-as-content* (P2): parity dot (odd hit count), checksum bar, `eventColorMode` that colorizes ONLY on failure events (slip/read-error/parity) with decay hold — "color is diagnostic" principle stated in comments.
- *Feedback memory* (P3): persistent buffer with zoom/rotate transform, decay, and — the loop-closer — **memory→threshold influence** (`thresh += (memory−0.5)·influence·0.3`): what the machine drew biases what it will draw. Plus memory corruption modes (bit-flip = `1−value`, threshold skew) gated per beat.
- *Instrument presets* (P3): `getInstrumentPreset(mode, intensity)` returning vec4(slip, error, corruption, quantize) — Baseline / Clock Slip Test / Read Error Stress / Corrupt Memory Recovery (+P4: Encoder Wall, Full Diagnostic), max-blended over manual controls.
- *Macro conductor* (P4): a slow macro clock assigns each tile a **state machine value** {ACTIVE, MUTE, SOLO, ERROR, RECOVER, DIAGNOSTIC} via patterned hashes (stripes/blocks/clusters/wave modes, group seeds, solo chance, mute floor, recovery windows). States modulate error rates (ERROR ×2, RECOVER ×0.5), contrast (SOLO 1.5×), mute, and DIAGNOSTIC force-enables glyphs/meta overlay. Ensemble choreography without any CPU.
- *Registers* (P4): the raw per-line hit bits (`rawBits[32]`, captured pre-render-mode) re-rendered as bitplane columns / barcode / 3-stack shifted registers / mixed, blended with the "physical" lines by `physicalLayerMix` — the machine displays its own internal state.
- *Glyph layer* (P4): SDF primitives — `sdSegment`, corner brackets, tick rulers, and a full **7-segment digit SDF** (`sdSevenSegment` with per-digit boolean segment tables) rendering the tile's state number; calibration notches + crosshair layer.
- *P5 (day31_08)*: top-level ◆ VJ macro row (CHAOS/DENSITY/SPEED/COMPLEXITY/CONTRAST/GLITCH/PULSE/MORPH/EVOLUTION/ACCENT) feeding everything (chaos squared for low-end resolution; complexity adds grid cells and lines); instrument **suites** with lock strength and override mix; a 2D **cellular automaton** layer (neighbor average vs rule threshold 0–255, stability blend) that modulates macro density and tile timing; a **microprogram sequencer** — 12 opcodes (`OP_NUDGE_SLIP`, `OP_BURST_ERROR`, `OP_SHIFT_THRESH`, …) fetched per program tick from hashed "instructions," with mutation mode and loop point, plus an on-screen program progress readout; simulated audio-reliability modulation (BPM-derived pseudo-audio smoothed and routed to timing/error/threshold).
- day31_07 is a transitional build labeled P5 (defines the opcode set) but whose main() is the P4 architecture — a snapshot mid-migration.

**Control/UI design.** The corpus's most extreme: P5 has ~110 inputs. Conventions: `ui_*` float dummies (later `event` dummies) with ━━/▓▓/██ hierarchy dividers indicating importance tiers; ⚠️ = touching this changes the PRNG's identity; ★/◆ importance glyphs; "(0S 1X 2O 3A)" inline enum legends on float-as-enum controls (floats used instead of `long`, probably for MIDI-mappability); performance controls first, forensic detail last.

**Version evolution.** 01: minimal port (91 lines). 02 UNHINGED: every constant exposed, + angle/AA/color/accumulation. 03 P1: clocked system + logic/register concept + hysteresis. 04 P2: scan/raster + morphology + diagnostics + event color. 05 P3: feedback memory + corruption + instrument presets. 06 P4: macro conductor + registers + glyphs + calibration + state map. 07: P5-labeled P4 snapshot. 08 P5: VJ macro layer + suites + automaton + microprogram + audio sim. A textbook staged build with each phase's systems kept and layered — and visible cost: the parameter-threading grows unwieldy, motivating DATAFIELD's restart.

**Complexity tier: 5** for P4/P5 (multi-pass, stateful, macro-conducted instrument with ~110 controls); 01 is tier 1.

**Signature moves.** PRNG constants as performance controls; deterministic hash-of-beat clock slip with relock envelope; logic-gate compositing of SDF hits; registers/glyphs rendering internal state; tile state machine conductor; microprogram opcodes; memory→threshold feedback.

**Rough edges.** `float hits[32]` arrays + fixed-bound loops everywhere (Metal-safe but heavy); day31_07's split identity; `lineIndex` coloring takes the *last* hit line (order-dependent); P5's audio is simulated only (no real audio input in the corpus's ISF hosts — acknowledged by "Audio RELIABILITY" being an influence-model, not FFT); hysteresis is a threshold-bias approximation, not true state (comments admit "soft state hold"); duplicated helper libraries pasted per version (~800 lines of shared code, no includes — an ISF constraint).

## Family 4: DATAFIELD (day31_09 – day31_21, day32_01, day32_02 — 15 files)

**Purpose & visual identity.** Generators (v3.x: filters) executing an explicit **Ryoji Ikeda methodology** — stated in header comments with a quotation and numbered principles: binary states only (`step()` everywhere, "white is voltage, not highlight"), clocked time, scanning as physical metaphor, density as drama, sync/lock/dropout, measurement aesthetics, no color/softness/decoration. Output is monochrome data-brutalism: grids of bit cells, barcode stripe bands, scanlines, calibration brackets, hex readouts.

**Architecture.** 09: 2 passes (`memory` persistent + screen). v2.x: `field_buffer` (persistent FLOAT) + screen; v2.3+ add `proc_buffer` (persistent — the "proof" buffer); v3.0: filter with `analysis_buffer` + `history_buffer` + screen; v3.1: **4 passes** (`analysis_buffer`, `history_buffer` [4-channel: history/accum/peak/avg], `error_buffer` for cascade memory, composite). A `Clock` **struct** (tick/phase/beat/slipAmt/subTick/tickLen/measure/beatEnv) built by one constructor — structs are unique to this family in the corpus.

**Techniques.**

## Family 5: GLitcher (AR_GLitcher_02, AR_GLitcher_04 — 2 files)

**Purpose & visual identity.** Filters: recursive compound-grid UV scrambler based on Karl Gerstner's grid-design ideas and a 2/3 ratio — the input image shattered into re-scaled, re-offset grid cells at multiple recursion depths, with random zoom/pan reframing. The oldest code style in the batch (CREDIT field with the author's email; lowercase `"persistent": true`; `IMG_THIS_PIXEL`).

**Architecture.** Single logical pass into a persistent `buffer` (02 uses it for feedback; 04 declares it but no longer reads it — vestigial).

**Techniques.**
- *Compound grid*: cellSize `vec2(2/3/complexity, 1/complexity)` (the 2/3 Gerstner ratio); per-cell hashed offset+scale transform with `fract()` wrap; `applyCompoundGrid = mix(chaotic grid, straight ratio grid, chaosFactor)` — chaos literally interpolates between an ordered and a scrambled grid.
- *Recursion*: `for i < repetitions: loc = applyCompoundGrid(loc, complexity * 2^i …)` — exponentially finer scrambling per iteration (04 softens to `1 + i/reps`).
- *Random reframe*: `randomPaddedZoomedPositionWithSeed` — hashed zoom (min-zoom floored at 4px), hashed center in pixel units, hashed padding, `fract` wrap; seeds built from odd vec2 constant recipes (`seed*vec2(0.128,9.21)+vec2(1.42,2.17)` etc.).
- *Chaotic feedback* (02): buffer sampled at a time-sinusoidal random offset, RGB partially replaced by pure hash noise scaled by chaos, mixed by `feedbackLoop`.
- *Multiplicative grain* (02): `x=(u+4)(v+4)(t·10); grain = mod((mod(x,13)+1)(mod(x,123)+1), 0.01) − 0.005` — the classic mod-cascade film grain.
- *Premultiplied accumulation*: `rgb += tmp.rgb * tmp.a; a = min(a + tmp.a, 1)` inside a bounds check.
- 04: transforms centered on cell midpoints (`uv -= cellSize*0.5 … +=`) so distortion scales around cell centers, and a **single `organicDistortion` dry/wet macro** smoothstepped and multiplied into chaos/offset/zoom/pad — a full-effect bypass fade (the earliest "conductor knob" in the author's lineage). **Version evolution (02→04).** Removes feedback/grain (04 is the "clean" variant), centers cell transforms, softens recursion growth, adds the organicDistortion dry/wet macro. These files are the ancestors of the corpus's later habits: seed-recipe hashing, chaos-as-interpolant, macro dry/wet.
