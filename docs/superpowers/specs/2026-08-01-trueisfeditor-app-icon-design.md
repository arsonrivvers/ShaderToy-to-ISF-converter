# TrueISFEditor App Icon Design

## Goal

Replace TrueISFEditor's generic macOS application icon with a simple, recognizable icon that remains legible in the Dock, Finder, Spotlight, and system settings.

## Format

- Current macOS rounded-square application-icon silhouette.
- Master artwork composed at 1024 × 1024 pixels.
- Important artwork remains inside a generous safe area so it survives macOS masking and small-size rendering.
- No transparency-dependent outer silhouette, fine linework, watermark, or ornamental micro-detail.

## Visual Directions

Generate three comparison concepts:

1. **ISF monogram — lead direction.** Large, bold `ISF` lettering over a restrained violet-to-cyan shader-like color field. This should be the clearest option at small sizes.
2. **Shader window.** A minimal preview rectangle combining a smooth color field with simple code-bracket symbolism.
3. **True / ISF stack.** A compact two-line typographic treatment using `True` above `ISF`.

## Style

The icon should feel like a focused creative-development tool: modern, precise, slightly luminous, and unmistakably related to real-time shader work. Depth may come from subtle gradients and restrained edge lighting, but it should not look glossy, photorealistic, busy, or game-like.

## Palette

Use a dark near-black or deep indigo foundation with a restrained violet, electric blue, and cyan color field. Maintain strong contrast around typography and avoid muddy intermediate colors.

## Selection Criteria

The winning icon must:

- Read immediately at 32 × 32 pixels.
- Remain recognizable without relying on the full application name.
- Avoid confusing `ISF` with `ISO`, `1SF`, or other letterforms.
- Look native beside contemporary macOS application icons.
- Feel appropriate for both an editor and a real-time visual tool.

## Deliverables

- Three square preview concepts for visual selection.
- One selected 1024 × 1024 master.
- A complete macOS AppIcon asset set derived from the approved master during implementation.

## Scope

This pass changes only the TrueISFEditor application icon. It does not create a broader identity system, wordmark, splash screen, or ARShader icon.
